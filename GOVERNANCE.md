# Governance

Pain001.com is maintained by Sebastien Rousseau. Decisions are made in the
open through GitHub issues and pull requests, guided by user safety,
standards accuracy, accessibility, security, and long-term maintainability.

The maintainer has final responsibility for releases, security response,
domain operations, and project scope. Material decisions should be recorded
as architecture decision records under `docs/adr/`. Contributors may appeal
a decision by opening a focused issue with new technical evidence.

Inactive ownership is addressed by transferring repository and domain access
to a trusted project contributor before any planned departure. Security
contacts are kept current in `SECURITY.md` and `static/security.txt`.
