Pain001 telepítése: pip, Docker, első validált fájl

Python 3.10–3.12, pip vagy Docker, és három paranccsal kész a validált fizetési fájl.

2 perc olvasás Utolsó ellenőrzés 2026-07-26

Tartalom

  1. PyPI
  2. Docker
  3. Zárt környezetek
  4. Az első fájl három paranccsal

A Pain001 Python 3.10, 3.11 és 3.12 alatt fut (mindegyik verzió tesztelve a CI-ban) macOS, Linux és Windows rendszeren. Csak azt telepítse, amire szüksége van; minden opcionális képesség egy extra, így az alaptelepítés karcsú marad.

01. PyPI#

Mire van szüksége Parancs
Alap CLI és Python könyvtár pip install pain001
REST API mikroszolgáltatás (FastAPI + Uvicorn) pip install "pain001[api]"
Parquet fájlok beolvasása (PyArrow) pip install "pain001[parquet]"
PGP-vel titkosított bemeneti fájlok (.gpg / .asc) pip install "pain001[gpg]"
Redis alapú aszinkron feladatsor az API-hoz pip install "pain001[redis]"
OpenTelemetry nyomkövetés pip install "pain001[otel]"
Beépített minimális MCP / LSP kiszolgálók pip install "pain001[mcp]" / "pain001[lsp]"

A kiegészítő csomagok külön telepíthetők, és önálló verziószámozást követnek:

pip install pain001-loader-xlsx    # Excel ingestion (auto-discovered plugin)
pip install pain001-loader-mt101   # SWIFT MT101 parsing library
pip install pain001-mcp            # Full 17-tool MCP server for AI agents
pip install pain001-lsp            # Full six-feature editor language server

Ellenőrizze a telepítést, és tekintse át az üzenetkatalógust:

pain001 --version
pain001 versions          # list all 11 supported message definitions
pain001 init pain.001.001.09   # scaffold a starter CSV template

02. Docker#

A több architektúrát támogató képfájlok (linux/amd64, linux/arm64) a GitHub Container Registry szolgáltatásban jelennek meg. A konténer dedikált, nem root felhasználóként fut.

# Generate XML from a local CSV
docker run --rm -v "$PWD:/data" -w /data \
  ghcr.io/sebastienrousseau/pain001:latest \
  generate -t pain.001.001.09 -d payments.csv -o out/

# Launch the REST API
docker run --rm -p 8000:8000 \
  ghcr.io/sebastienrousseau/pain001:latest \
  serve --host 0.0.0.0 --port 8000

03. Zárt környezetek#

A banki és treasury környezetek gyakran tiltják a bővítmények dinamikus betöltését. Pontosan erre az esetre két szabályozási lehetőség áll rendelkezésre:

  • PAIN001_DISABLE_PLUGINS=1 kikapcsolja a külső bővítmények teljes felismerését; csak a csomaggal szállított betöltők futnak.
  • pain001 plugins list / pain001 plugins show make every discovered plugin auditable before first use.

Minden helyben fut. A csomagcsalád egyetlen csomagja sem küld haza adatokat, nem hív SaaS API-t, és nem viszi ki a fizetési adatokat a gazdagépről.

04. Az első fájl három paranccsal#

pip install pain001
pain001 init pain.001.001.09 -o work/
pain001 -t pain.001.001.09 -d work/template.csv -o work/ --dry-run

A --dry-run a JSON Schema, az XSD és (a --scheme kapcsolóval) egy SEPA vagy határon átnyúló szabálykönyv alapján validál, kimenet írása nélkül — a 0 kilépési kód azt jelenti, hogy a fájl átment ezeken az ellenőrzéseken: a séma ellenőrzésén, és, ha ki lett választva, a szabálykönyv ellenőrzésén. A bankja saját profilja és csatornaszabályai ettől függetlenek, és továbbra is banki tesztelést igényelnek. Hagyja el a --dry-run kapcsolót az XML kiírásához.

Folytassa a műszaki referenciával az összes kapcsolóért és végpontért, vagy a gyorsindítási GYIK-kel az üzemeltetési kérdésekhez.
