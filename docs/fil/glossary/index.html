Glossary ng ISO 20022 na Pagbabayad sa Simpleng Wika

Ang bokabularyo ng pagbabayad sa simpleng wika — para sa mga taong pumipirma sa mga file, hindi lamang sa mga bumubuo ng mga ito.

3 min na pagbasa Huling suri 2026-07-26

Mga Nilalaman

  1. Mga Mensahe
  2. Mga scheme at rulebook
  3. Mga identifier at data
  4. Mga terminong pang-tooling na ginagamit sa site na ito

Mga kahulugan sa simpleng wika ng mga terminong lumilitaw sa buong site na ito at sa channel documentation ng inyong bangko. Isinulat una para sa mga treasurer at operations team, pangalawa para sa mga inhinyero.

Mga Mensahe#

pain.001 — Customer Credit Transfer Initiation. Ang XML na mensaheng ipinapadala ng customer sa kaniyang bangko upang mag-utos ng isa o higit pang credit transfer. Ang pamilyang "pain" ay payment initiation; ang .001 ay ang numero ng mensahe; itinatakda ng huling bersyon (.001.09) ang schema.

pain.002 — Customer Payment Status Report. Ang sagot ng bangko sa inyong pain.001 o pain.008: tinanggap, bahagyang tinanggap, o tinanggihan, na may mga ISO reason code bawat transaksyon.

pain.008 — Customer Direct Debit Initiation. Ang kambal na pang-koleksyon ng pain.001: sinisingil ninyo ang mga pondong inutang sa inyo sa ilalim ng isang mandato sa halip na magpadala ng pondo palabas.

pacs.008 / pacs.009. Ang mga interbank settlement na mensaheng kinauuwian ng inyong tagubilin kapag tinanggap ito ng bangko. Hindi kailanman inaakda ng mga korporasyon ang mga ito; ang mga bangko ang nagpapalitan ng mga ito.

camt.052 / camt.053 / camt.054. Pag-uulat ng account: intraday na ulat, end-of-day na statement, at abiso ng debit/credit ayon sa pagkakabanggit. Ang camt.053 ang kinokonsumo ng mga reconciliation team tuwing umaga.

MT101. Ang legacy na SWIFT na text na mensaheng "Request for Transfer" na pinapalitan ng pain.001. Ang interbank na MT101 relay ay ide-decommission sa 14 Nobyembre 2026 pabor sa pain.001.001.09; ang corporate-to-bank na MT101 ay nananatili lamang ayon sa pagpapasya ng bawat bangko.

Mga scheme at rulebook#

SEPA SCT / SCT Inst. Ang mga euro credit-transfer scheme (standard at instant) na pinamamahalaan ng mga rulebook ng European Payments Council. Ang mga instant na transfer ay nase-settle sa loob ng ilang segundo, buong araw at gabi.

SEPA SDD Core / B2B. Ang mga euro direct-debit scheme — Core para sa mga consumer (may karapatan sa refund), B2B para sa mga negosyo (walang karapatan sa refund, mas mahigpit na pagsusuri ng mandato).

CBPR+. Cross-Border Payments and Reporting Plus: ang mga usage guideline na nagpo-profile ng mga ISO 20022 na mensahe para sa SWIFT correspondent banking. Kapag sinabi ng mga tao ang "ang SWIFT ISO 20022 migration", ang tinutukoy nila ay CBPR+.

HVPS+. Ang katumbas na profiling para sa mga high-value payment system (T2, CHAPS, Fedwire at mga kapareho).

CGI-MP. Common Global Implementation — Market Practice: ang grupong nagpapantay ng paggamit ng mga korporasyon sa mga pain na mensahe sa iba't ibang bangko, upang ang isang format ng file ay makapagsilbi sa maraming banking partner.

Verification of Payee (VoP). Ang iniuutos ng EU na pagsusuri sa pagtutugma ng pangalan/IBAN na inilalapat sa lahat ng SEPA credit transfer mula 9 Oktubre 2025. Ginagawa ng PSP sa oras ng pagpapatupad; ang malinis na data ng creditor ang nagtatakda kung tutugma ito.

Mga identifier at data#

IBAN. International Bank Account Number (ISO 13616), self-checking sa pamamagitan ng mod-97 checksum — kaya't ang isang nagkapalit na digit ay natutukoy bago ang pagsusumite.

BIC / BICFI. Ang ISO 9362 Business Identifier Code ng isang institusyong pampinansyal. Ang XML element ay sa pain.001.001.03 ngunit mula sa bersyon 9 — isang pagpapalit ng pangalan na nagdudulot ng mga totoong pagtanggi sa panahon ng pag-upgrade ng bersyon.

LEI. Legal Entity Identifier (ISO 17442) — ang 20-character na pandaigdigang identifier ng kumpanya. Mahigit 3 milyon ang aktibo, at lalong iniuutos ng mga regulator ang mga ito sa mga pagbabayad.

UETR. Unique End-to-end Transaction Reference — ang UUID na nagpapahintulot na masubaybayan ang isang pagbabayad sa buong correspondent chain (SWIFT gpi).

Structured / hybrid na address. Mga postal address bilang mga hiwalay na XML element (kalye, bayan, postcode, bansa) kumpara sa mga free-text na linya. Mula 14 Nobyembre 2026, tinatanggihan ng CBPR+ ang ganap na unstructured na mga address; ang hybrid — structured na bayan at bansa kasama ang hanggang dalawang 70-character na linya ng address — ay nananatiling wasto.

NbOfTxs / CtrlSum. Ang mga control total sa group header: bilang ng mga transaksyon at suma ng halaga. Muling kinukuwenta ng mga bangko ang mga ito; kung hindi tugma ang sa inyo, babalik ang file. Palaging kinukuha ng Pain001 ang mga ito mula sa mga na-validate na record.

Charge bearer. Kung sino ang magbabayad ng mga bayarin: DEBT (nagpadala), CRED (tumanggap), SHAR (hinati), SLEV (ayon sa mga panuntunan ng scheme). Ang legacy na MT na OUR/BEN/SHA ay tumutugma sa unang tatlo.

Remittance information. Ang field na "para saan ang bayad na ito" — free text (140 character) o mga structured na reference. Ang bagay na hinihiling ng mga reconciliation team na punan nang maayos ng lahat.

Mga terminong pang-tooling na ginagamit sa site na ito#

XSD validation. Ang pagsusuri sa XML laban sa opisyal na ISO 20022 schema definition. Itinuturing ito ng Pain001 na isang mahigpit na gate bago maisulat ang anumang file.

MCP — Model Context Protocol. Ang bukas na pamantayan kung saan tumatawag ang mga AI assistant ng mga panlabas na tool. Inilalantad ng pain001-mcp ang 17 payment tool sa anumang MCP client, nang lokal sa pamamagitan ng stdio.

LSP — Language Server Protocol. Ang pamantayan sa editor integration sa likod ng mga IDE diagnostic. Ginagamit ito ng pain001-lsp upang i-validate ang mga payment file habang kayo ay nagta-type.

SBOM. Software Bill of Materials — isang machine-readable na imbentaryo ng bawat dependency sa isang release, na binubuo sa CycloneDX na format para sa mga core release ng Pain001.

May kulang ba? Magmungkahi ng termino — lumalago ang glossary na ito kasabay ng mga tanong na aktwal na itinatanong ng mga tao.
