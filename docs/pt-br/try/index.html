Demonstração interativa

Experimente o Pain001 no seu navegador

Arraste um CSV, use o exemplo ou cole seus próprios registros — a validação é executada na hora, inteiramente no seu navegador, e nada sai da sua máquina.

Como este validador ajuda você

  • ✓Teste os dados de pagamento com as verificações que os bancos aplicam — campos obrigatórios, dígitos verificadores do IBAN, estrutura do BIC, totais de controle
  • ✓Gere um arquivo de transferência pain.001.001.09 funcional que você pode inspecionar, copiar ou baixar
  • ✓Comprove o resultado contra o esquema oficial ISO 20022 — o XSD genuíno, validado no seu navegador

Informações importantes

  • Nada é enviado. Seu arquivo é lido pelo seu próprio navegador e nunca sai da sua máquina — não há servidor, armazenamento nem telemetria. Seguro para dados reais, embora usar dados de teste mascarados seja sempre uma boa prática.
  • Ferramenta apenas para testes. Os arquivos nunca são submetidos a processamento e nenhum pagamento pode resultar do que você fizer aqui.
  • Colunas esperadas: payment_id, payment_amount, currency, nome / IBAN / BIC do devedor e do credor, requested_execution_date — os delimitadores vírgula, ponto e vírgula e tabulação são detectados automaticamente. Baixe um exemplo abaixo para usar como modelo da sua própria exportação.
  • Sem custos. Esta ferramenta, e o conjunto completo de ferramentas por trás dela, são gratuitos e de código aberto.

Verifique você mesmo

“Nada é enviado” é uma afirmação que você pode comprovar em dois minutos:

  1. Abra o DevTools → Network e use a demonstração. As únicas requisições são GETs de mesma origem para os recursos desta página, o motor WASM e o esquema — nenhuma delas transporta seus dados.
  2. Execute a validação XSD uma vez e depois coloque o DevTools em Offline (ou desligue o Wi-Fi). Toda a demonstração — incluindo a validação com o esquema oficial — continua funcionando: um service worker armazena tudo em cache após o primeiro uso.
  3. Esta página também é de código aberto — a lógica da demonstração é um único módulo sem dependências que você pode ler por completo.

Não há script de analytics, serviço de relatório de erros, fonte de terceiros nem endpoint de relatórios CSP — o próprio relatório seria uma conexão de saída.

    O que esta demonstração mostra — e o que o pipeline real acrescenta

    Cada lote de exemplo também pode ser baixado como arquivo CSV para servir de modelo à exportação do seu próprio ERP ou planilha — a linha de cabeçalho é o contrato.

    A demonstração acima implementa a camada fail-fast do pipeline do Pain001: verificação de campos obrigatórios, dígitos verificadores IBAN mod-97 conforme a ISO 13616, estrutura BIC conforme a ISO 9362, formatos de valor e data, e totais de controle (NbOfTxs, CtrlSum) recalculados a partir dos registros em vez de aceitos como estão. Experimente o menu “Introduzir um erro…” — cada cenário insere exatamente uma falha realista (um dígito de IBAN trocado, um BIC malformado, uma coluna ausente, um valor europeu com vírgula decimal, uma data impossível) e mostra o apontamento no nível da linha que o gateway de um banco só reportaria dias depois.

    O conjunto de ferramentas instalado executa uma verificação muito mais profunda: validação com JSON Schema por registro com normalização de aliases de campos, cinco conjuntos de regras de esquema (SEPA SCT, Instant, SDD Core, B2B, internacional) com saída --explain regra a regra, e validação final do documento gerado contra o XSD oficial da ISO 20022 antes que um único byte seja gravado. Dez versões de pain.001 e pain.008.001.02 são suportadas.

    pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --scheme sepa-sct --dry-run

    A etapa 3 acima não é uma simulação: ela inicia um runtime Python em WebAssembly e executa o xmlschema contra o esquema oficial pain.001.001.09, servido por este site — a mesma classe de validação XSD que a CLI aplica. O que permanece exclusivo da CLI é o restante do pipeline: a normalização com JSON Schema, os cinco conjuntos de regras com --explain, e as outras dez definições de mensagem.
