交互式演示

在浏览器中试用 Pain001

拖入 CSV 文件、使用示例或粘贴您自己的记录——验证即时运行，完全在您的浏览器中进行，任何数据都不会离开您的设备。

此验证工具如何为您服务

  • ✓按照银行所采用的检查测试付款数据——必填字段、IBAN 校验和、BIC 结构、控制总额
  • ✓生成一个可用的 pain.001.001.09 贷记转账文件，供您查看、复制或下载
  • ✓依据官方 ISO 20022 Schema 验证结果——货真价实的 XSD，在您的浏览器中完成验证

重要信息

  • 不会上传任何数据。您的文件由您自己的浏览器读取，绝不会离开您的设备——没有服务器、没有存储、没有遥测。可安全用于真实数据，但使用脱敏的测试数据始终是良好实践。
  • 仅为测试工具。文件绝不会被提交处理，您在此进行的任何操作都不会产生任何付款。
  • 预期列： payment_id, payment_amount, currency, 付款人与收款人名称 / IBAN / BIC, requested_execution_date ——逗号、分号和制表符分隔符均可自动检测。请在下方下载示例，作为您自己导出文件的模板。
  • 不收取任何费用。此工具及其背后的完整工具链均为免费开源软件。

亲自验证

“不会上传任何数据”是一项您可以在两分钟内自行证伪的声明：

  1. 打开 DevTools → Network，然后使用本演示。仅有的请求是用于获取本页资源、WASM 引擎和 Schema 的同源 GET 请求——没有任何请求携带您的数据。
  2. 先运行一次 XSD 关卡，再将 DevTools 切换为离线模式（或关闭 Wi-Fi）。整个演示——包括官方 Schema 关卡——仍然可用：Service Worker 会在首次使用后缓存所有内容。
  3. 本页面同样开源——演示逻辑是一个零依赖模块，您可以完整阅读其源代码。

没有分析脚本、没有错误上报服务、没有第三方字体，也没有 CSP 报告端点——上报本身就已是一次对外连接。

3

依据官方 ISO 20022 XSD 进行验证

第 1–2 步运行的是快速的手写检查。此步骤运行的则是货真价实的验证：一个 Python 运行时（通过 WebAssembly）执行 xmlschema ，依据官方 pain.001.001.09 Schema 进行验证—— 与 CLI 所执行的验证属于同一级别。约 13 MB 的引擎由本 站点提供，仅在您请求时下载一次（当第 2 步生成有效 XML 后， 它便会开始静默下载）。

请先在第 2 步生成 XML——XSD 关卡验证的正是该输出。

    本页面的一切都在您的浏览器中运行——不会上传、存储或向任何地方发送任何数据。 本演示实现了流水线的一个子集（必填字段、IBAN mod-97、BIC 结构、金额 与日期格式、重新计算的 NbOfTxs/CtrlSum 控制总额）。第 3 步通过 WebAssembly 就地运行官方 XSD 关卡。安装版工具链 在此之上还提供 JSON Schema 验证和五套方案规则手册—— 安装 CLI 以获得完整流水线。

    本演示展示的内容——以及真实流水线的额外能力

    每个示例批次也可作为 CSV 文件下载，用作您自己 ERP 或电子表格导出的模板——表头行即是契约。

    上方演示实现的是 Pain001 流水线的快速失败层：必填字段检查、ISO 13616 mod-97 IBAN 校验和、ISO 9362 BIC 结构、金额与日期格式，以及从记录重新计算而非直接信任的控制总额 (NbOfTxs, CtrlSum)。试试“引入错误…”菜单——每个场景都会植入恰好一个真实缺陷（IBAN 数字颠倒、BIC 格式错误、缺失列、欧式逗号小数金额、不可能的日期），并向您展示银行网关原本要在数日后才会报告的行级发现。

    安装版工具链运行的关卡则深入得多：对每条记录进行带字段别名归一化的 JSON Schema 验证、五套方案规则手册（SEPA SCT、Instant、SDD Core、B2B、跨境）并逐条规则输出 --explain，以及在写出任何一个字节之前依据官方 ISO 20022 XSD 对渲染后文档的最终验证。支持十个 pain.001 版本及 pain.008.001.02。

    pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --scheme sepa-sct --dry-run

    上方第 3 步并非模拟：它在 WebAssembly 中启动一个 Python 运行时，并依据由本站点提供的官方 pain.001.001.09 Schema 运行 xmlschema——与 CLI 应用的 XSD 关卡属于同一级别。仍仅限 CLI 的是流水线的其余部分：JSON Schema 归一化、带 --explain 的五套方案规则手册，以及其余十种报文定义。
