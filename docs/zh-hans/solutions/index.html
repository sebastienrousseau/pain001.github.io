财资与财务#

您的银行会以 ERP 从未提醒过您的理由退回文件：IBAN 数字换位、控制总额不再匹配、地址格式不再被接受。Pain001 让这些故障提前在您的案头暴露——每个文件在提交前都依据银行的官方规则手册（ISO 20022 XSD）得到证明，支付生命周期指南展示了每项检查在发起与对账之间所处的位置。如果这些术语对您还很陌生，请从术语表开始；那些通俗易懂的定义是为您这一侧的办公桌而写，而非为工程师。

CFO 与董事会#

两个数字框定了这项决策。2026 年 11 月 14 日：携带非结构化地址的跨境支付开始在网络层面被退回的日期——风险敞口存在于您的客户主数据中，而非您的银行连接。每年 €10,000–30,000：最接近的商业转换 SDK 的公开标价，而 Pain001 在开放许可下、任何规模均永久免费。治理问题——可审计性、数据本地性、供应链证据——以实物凭证而非口头保证作答：公开发布的 SBOM、安全政策，以及绝不离开您基础设施的处理流程。一页高管简报专为转发而写。

支付运营#

您的日常就在响应文件里。Pain001 端到端闭环：--dry-run 提交前检查在 CI 中干净地通过或失败，逐条解读的清算方案规则手册（SEPA 与跨境），用于解码回执的 pain.002 原因代码参考，以及将银行响应和 camt.053 对账单转换为您的流水线可路由的结构化数据的解析器。浏览器演示是了解它所消除的故障类别的最快方式——包括一键“引入错误”场景。

工程与 AI#

类型化的 Python API、带有明确退出码的 CLI、REST 微服务，以及面向加载器、校验器、清算方案和写入器的插件点——技术参考覆盖每一个标志与端点，代码以 100% 行与分支覆盖率作为硬性 CI 门槛。如果您在构建智能体：pain001-mcp 是该类别中唯一的 Model Context Protocol 服务器——十七个只读工具供您的智能体在本地调用，并由 pain001-lsp 提供编辑器诊断，同时人类始终在环。
