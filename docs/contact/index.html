Contact Pain001: Support, Security and Enquiries

Where to report bugs, disclose security issues privately, and reach the maintainer — with what to include for the fastest possible fix.

Prefer another channel? Bugs and features: GitHub issues. Security: private vulnerability reporting (see security.txt). Email: contact@pain001.com.

Bug reports and feature requests — GitHub issues for the core, or the matching repository for pain001-mcp, pain001-lsp, and the loaders. Include your package version (pain001 --version), the message type, and a minimal reproducing input with real account data removed.

Security disclosures — please use GitHub's private vulnerability reporting rather than a public issue. Coordinated disclosure is welcomed and credited. A machine-readable policy is published at /security.txt.

Everything else — email contact@pain001.com, or find the maintainer at sebastienrousseau.com.

This is an open-source project, not a vendor helpdesk: issues are triaged in public, and well-written reports with reproductions get fixed fastest.
