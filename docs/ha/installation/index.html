Shigar da Pain001: pip, Docker da Fayil na Farko

Python 3.10–3.12, pip ko Docker, da fayil ɗin biya da aka tantance cikin umarni uku.

2 mintuna na karatu Bita ta ƙarshe 2026-07-26

Abubuwan da ke ciki

  1. PyPI
  2. Docker
  3. Muhallai masu tsauraran ƙa'idoji
  4. Fayil na farko cikin umarni uku

Pain001 tana aiki kan Python 3.10, 3.11, da 3.12 (an gwada kowace siga a CI) a kan macOS, Linux da Windows. Ka shigar da abin da kake buƙata; kowace fasaha ta zaɓi ƙari ce daban, don haka shigarwar tushe tana kasancewa mai sauƙi.

01. PyPI#

Abin da kake buƙata Umarni
CLI na tushe & ɗakin karatu na Python pip install pain001
Ƙaramar hidimar REST API (FastAPI + Uvicorn) pip install "pain001[api]"
Karɓar bayanan Parquet (PyArrow) pip install "pain001[parquet]"
Fayilolin shigarwa da aka ɓoye da PGP (.gpg / .asc) pip install "pain001[gpg]"
Jerin gwanon ayyukan async na API bisa Redis pip install "pain001[redis]"
Bin diddigi na OpenTelemetry pip install "pain001[otel]"
Sabar MCP / LSP masu ƙarancin fasali da ke ciki pip install "pain001[mcp]" / "pain001[lsp]"

Ana shigar da ƙarin fakitocin daban kuma suna da sigogi masu zaman kansu:

pip install pain001-loader-xlsx    # Excel ingestion (auto-discovered plugin)
pip install pain001-loader-mt101   # SWIFT MT101 parsing library
pip install pain001-mcp            # Full 17-tool MCP server for AI agents
pip install pain001-lsp            # Full six-feature editor language server

Tabbatar da shigarwa sannan ka bincika jerin saƙonni:

pain001 --version
pain001 versions          # list all 11 supported message definitions
pain001 init pain.001.001.09   # scaffold a starter CSV template

02. Docker#

Ana buga hotunan gine-gine daban-daban (linux/amd64, linux/arm64) a GitHub Container Registry. Kwandon yana aiki a matsayin mai amfani na musamman wanda ba root ba.

# Generate XML from a local CSV
docker run --rm -v "$PWD:/data" -w /data \
  ghcr.io/sebastienrousseau/pain001:latest \
  generate -t pain.001.001.09 -d payments.csv -o out/

# Launch the REST API
docker run --rm -p 8000:8000 \
  ghcr.io/sebastienrousseau/pain001:latest \
  serve --host 0.0.0.0 --port 8000

03. Muhallai masu tsauraran ƙa'idoji#

Muhallan bankuna da baitulmali sau da yawa suna hana ɗora plugins ta atomatik. Akwai matakan sarrafawa guda biyu domin wannan yanayin:

  • PAIN001_DISABLE_PLUGINS=1 yana kashe gano dukkan plugins na waje; loaders da aka haɗa a ciki kaɗai suke aiki.
  • pain001 plugins list / pain001 plugins show suna ba da damar bincika kowane plugin da aka gano kafin amfani da shi a karo na farko.

Komai yana aiki a cikin gida. Babu wani fakiti a cikin tsarin da ke aika bayanai zuwa waje, ko kiran SaaS API, ko fitar da bayanan biyan kuɗi daga na'urarka.

04. Fayil na farko cikin umarni uku#

pip install pain001
pain001 init pain.001.001.09 -o work/
pain001 -t pain.001.001.09 -d work/template.csv -o work/ --dry-run

--dry-run yana tantancewa bisa JSON Schema, XSD, da (tare da --scheme) littafin ƙa'idar SEPA ko na ƙasashen waje ba tare da rubuta fitarwa ba — lambar fita 0 na nufin fayil ɗin ya wuce waɗannan duban: duban schema, da kuma na littafin ƙa'idar scheme inda aka zaɓa. Bayanan martaba na bankinka da ƙa'idojin tashoshinsa abu ne daban, kuma har yanzu suna buƙatar gwaji tare da banki. Cire --dry-run don rubuta XML ɗin.

Ci gaba zuwa Jagorar Fasaha don kowace tuta da endpoint, ko zuwa Tambayoyin Farawa don tambayoyin ayyuka.
