Pain001 — ייזום תשלומים ISO 20022 בקוד פתוח

החבילה בקוד פתוח שהופכת את נתוני התשלומים שלכם ל-XML מאומת לפי ISO 20022 — מוכח כתקין לפני שהוא מגיע לבנק.

קובצי תשלום שהבנק שלכם לא ידחה#

Pain001 היא חבילת Python בקוד פתוח לייזום תשלומים לפי ISO 20022. היא ממירה את הנתונים שכבר יש לכם — CSV, Excel, SQLite, JSON, Parquet או הודעות SWIFT MT101 ישנות — ל-XML מסוג pain.001 (העברות) ו-pain.008 (הוראות קבע), מאומת מול סכמות ה-XSD הרשמיות.

כל קובץ עובר שלוש שכבות אימות לפני כתיבתו: סכמת JSON לכל רשומה (כולל בדיקת mod-97 ל-IBAN ומבנה BIC), כללי scheme (SEPA ו-CBPR+ חוצה גבולות) ואימות XSD סופי. סכומי הביקורת מחושבים מחדש, לעולם לא מועתקים. הכול רץ מקומית: שום נתון תשלום אינו עוזב את התשתית שלכם.

נסו בדפדפן#

אמתו אצוות דוגמה ישירות בדפדפן — דבר אינו מועלה — והוכיחו את התוצאה מול סכמת ה-XSD הרשמית: נסו את Pain001. קובצי CSV לדוגמה זמינים להורדה כתבניות לייצוא שלכם.

המועד האחרון: 14 בנובמבר 2026#

לאחר סיום הדו-קיום MT–MX ב-22 בנובמבר 2025, המועד הבא הוא 14 בנובמבר 2026: כתובות דואר לא מובנות לחלוטין יידחו בתשלומי CBPR+, וממסר MT101 הבין-בנקאי יוחלף ב-pain.001 גרסה 9. Pain001 תומך כבר היום בכתובות מובנות והיברידיות — וממיר MT101 בפקודה אחת.

מתחילים#

pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --dry-run

להמשך: מדריך התקנה, עיון טכני, מפת דרכים ISO 20022 עד 2028, קודי דחייה pain.002, מרכז אמון ותקציר מנהלים. התיעוד המלא באנגלית. רישיון כפול Apache-2.0 / MIT — שימוש מסחרי חופשי בכל קנה מידה.
