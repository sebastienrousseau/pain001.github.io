pain001-mcp: Model Context Protocol Server for AI Payment Tools

Exposing the Pain001 payment library as 17 first-class Model Context Protocol (MCP) agent tools for Claude Desktop, Cursor, and LLMs.

<div lang="en"><h1>pain001-mcp: Model Context Protocol Server</h1> <p><strong><code>pain001-mcp</code></strong> is an open-source Model Context Protocol (MCP) server that exposes the <code>pain001</code> ISO 20022 payment library as <strong>17 first-class agent tools</strong>.</p> <p>AI assistants and autonomous agents (such as Claude Desktop, Cursor, and custom FastMCP clients) can discover and invoke payment validation, charset transliteration, schema migration, and XML file generation directly within conversational workflows.</p> <hr /> <h2>Key Capabilities & Tools</h2> class="text-left"><code>generate_xml_string</code></td> <td align="left" class="text-left">Converts payment records into XSD-validated ISO 20022 <code>pain.001</code> or <code>pain.008</code> XML string.</td> </tr> <tr> <td align="left" class="text-left"><code>validate_identifier</code></td> <td align="left" class="text-left">Validates IBANs (ISO 13616 / mod-97 check) and BIC codes (ISO 9362).</td> </tr> <tr> <td align="left" class="text-left"><code>migrate_records</code></td> <td align="left" class="text-left">Round-trips and migrates payment records across schema versions (e.g. <code>pain.001.001.03</code> -> <code>pain.001.001.09</code> -> <code>.12</code>).</td> </tr> <tr> <td align="left" class="text-left"><code>sanitize_to_iso20022_charset</code></td> <td align="left"
