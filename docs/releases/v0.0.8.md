# pain001.com v0.0.8

Version 0.0.8 completes the layer-aware demo and corrects what the demo
page said about itself.

## What changed for readers

- **The error report carries its layers.** The report you download from the
  [browser demo](https://pain001.com/try/) now opens with one row per
  validation layer, stating what each concluded: ISO 20022 schema, data
  quality, scheme rulebook, your bank's profile and channel eligibility.
  The last two are always "not evaluated", because no local tool can know
  them. Each finding then names its layer, so a report handed to a
  colleague keeps the boundary of what was checked.
- **The demo describes itself accurately.** The explainer under the demo
  said the scheme rulebooks were CLI-only. The demo runs the pain001
  library itself, including the rulebook you choose (16 of the library's
  29) and the official XSD gate. The text now says so and lists what the
  installed CLI adds, in all 34 languages.
- **The demo speaks your language throughout.** Seven status strings,
  including the scheme verdicts shown in the summary and the report, had
  stayed in English on every translated page. Finding messages remain in
  English because the pain001 library produces them.
- **The generator is named correctly.** Every page's footer now reads
  "Built with the [Static Site Generator
  (ssg)](https://docs.static-site-generator.com/ssg/)".

## What changed for the repository

- The browser audits in CI now serve WebAssembly as `application/wasm`, as
  GitHub Pages does, so they exercise the demo after a validation runs
  instead of only the page before it.
- The roadmap marks Phase B, the layer-aware demo, as shipped.

The complete list is in `CHANGELOG.md` under 0.0.8.
