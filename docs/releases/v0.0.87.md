## Highlights ⭐️

* **CSP violation reports**: the events Worker takes Content Security Policy reports at `pain001.com/e/csp`, so the policy runs as Report-Only for a week before it is enforced. Each report keeps only the directive, page path, blocked origin and country.
* **Weekly rebuild**: the site rebuilds every Monday, so the traction figures on the governance page are never more than a week old.
* **No `workflow_run` trigger**: Suite Consistency audits the family daily and on dispatch, as the core does, instead of running with the default branch's trust on another workflow's completion.
* **In lockstep with pain001 0.0.87**: the browser runtime, snippet environment and corpus pages are pinned to the published core 0.0.87 wheel.
