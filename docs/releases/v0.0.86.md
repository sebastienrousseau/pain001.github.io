## Highlights ⭐️

* **100% coverage floors**: every Python script in `scripts/` and the shipped JavaScript are now held to 100% line and branch coverage by `make test` and CI.
* **Complexity gate**: Python functions are checked against the workspace complexity ceilings, with existing offenders recorded in a baseline that may only shrink.
* **One local gate**: `make check` runs every CI check locally, and the dev container boots straight into it.
* **In lockstep with pain001 0.0.86**: the site's version moves with the suite, and the browser runtime is pinned to the published core artifact before deployment.
