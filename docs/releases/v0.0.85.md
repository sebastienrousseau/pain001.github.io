## Highlights ⭐️

* **Open-source bank integration**: the site replaces paid offers with self-service evidence, maintenance guidance and private bank-profile recipes.
* **Privacy and language coverage**: first-party event counts honor browser privacy signals, and six languages are indexed while the remaining translations stay available.
* **Reliable build gates**: responsive hero preloads and bounded image encoding keep the demo inside its performance budget. Transient PyPI connection resets receive bounded retries while permanent failures still stop validation.
* **Suite 0.0.85**: website metadata and packaging move with all nine repositories. The browser runtime is pinned to the published core artifact before deployment.
