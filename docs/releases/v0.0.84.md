## Highlights ⭐️

* **Verify every suite publication**: daily and post-publication audits check all nine repositories and their distribution channels. The website rechecks after its main deployment completes and retains JSON evidence.
* **Review regenerated sources in the suite PR**: library regeneration produces a source patch and SHA-256 checksum with read-only permissions. Updates pass through the approved iteration and signed commit process.
* **In lockstep with pain001 0.0.84**: update the browser runtime, core wheel hash, generated version stamps and content from the published core artifacts before deployment.

* **Manual deployment recovery**: a manual CI run on main builds, audits and deploys the website through the same gates as a push. It can redeploy an approved main commit without adding a source change.
