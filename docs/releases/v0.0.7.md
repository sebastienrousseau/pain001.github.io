# pain001.com v0.0.7

Version 0.0.7 is a correction and hygiene release. The site's public claims
now match what it does, the generator is called by its name, and the
repository has no open security alerts.

## What changed for readers

- **The build page has its right name.** "Made with Shokunin" is now
  [Made with ssg](https://pain001.com/made-with-ssg/), naming the
  [Static Site Generator (ssg)](https://docs.static-site-generator.com/ssg/).
  The old address redirects. The page also now lists every script the site
  runs (theme and motion, navigation, search, a cookie-free page-view
  beacon) and names the browser demo's WebAssembly runtime as the one
  exception to "no runtime", where it had claimed only theme and navigation.
- **The accessibility statement describes the scan that runs.** Every
  published page is checked with the full axe rule set, including the AAA
  7:1 contrast rule, plus WAVE's documented rules, in both light and dark
  themes. The statement had named a sampled pa11y scan and miscounted its
  pages.

## What changed for the repository

- **No open Dependabot alerts.** pa11y-ci was the only route to
  `extract-zip`, whose two high advisories have no patched release. It is
  removed; the site-wide scan already covered every page it sampled, and
  the audit-exception list is empty.
- **The README is accurate and renders anywhere.** The logo and a light and
  dark screenshot of the current design are served from pain001.com, so
  they show outside GitHub too. Its claims were corrected against the
  repository: the Lighthouse gate (13 routes, five profiles), the JSON-LD
  actually emitted, the agent files that exist, the Python version CI runs,
  the seven workflows, the full build order, and framing, which Cloudflare
  already restricts.
- **Every version-bearing file agrees.** `package.json` and the lockfile
  root had stayed at 0.0.3; they now match `VERSION`.

The complete list is in `CHANGELOG.md` under 0.0.7.

## Verify this release

The assets are `pain001-site-v0.0.7.tar.gz`, its CycloneDX SBOM
`pain001-site-v0.0.7.cdx.json`, and `SHA256SUMS`. Build provenance and the
SBOM are attested; check them with:

```sh
gh attestation verify pain001-site-v0.0.7.tar.gz --repo sebastienrousseau/pain001.github.io
gh attestation verify pain001-site-v0.0.7.tar.gz --repo sebastienrousseau/pain001.github.io --predicate-type https://cyclonedx.org/bom
sha256sum --check SHA256SUMS
```

The checksums are appended below once the assets are published.
