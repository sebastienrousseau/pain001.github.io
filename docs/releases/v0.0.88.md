## Highlights ⭐️

* **The SDKs join the suite**: "The Pain001 suite" on the homepage and the README component table list the Go, Java, Rust, .NET and C++ SDKs, each linking its manual.
* **Search Console findings fixed**: corpus `Dataset` descriptions are 50 to 5000 characters and name their catalogue in `includedInDataCatalog`, breadcrumb pages carry a `BreadcrumbList` again, and titles and meta descriptions fit search results in every locale. A build gate keeps the lengths from drifting back.
* **ssg 0.0.76**: the site is built with the latest ssg release in CI, regeneration and both release workflows.
* **In lockstep with pain001 0.0.88**: the browser runtime, snippet environment and corpus pages are pinned to the published core 0.0.88 wheel.
