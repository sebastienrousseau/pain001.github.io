## Highlights ⭐️

* **Noindex pages stop naming themselves canonical**: the translated corpus scenario pages, `/offline/` and `/thanks/` keep their noindex but drop the self-canonical link that Search Console flagged as a conflict.
* **Every sitemap URL is checked**: `scripts/validate_sitemap.py` runs on every build and fails it unless each sitemap URL is a built, indexable, self-canonical page.
* **minimatch advisory closed**: `package.json` overrides minimatch to `^11.0.1` (GHSA-g3hv-75wg-m249), which eslint still pulls in at `^10`.
* **Built with ssg 0.0.72**: every workflow reads one `SSG_VERSION`, and pages with the contents rail keep full-width rules now that ssg no longer wraps the body in `<div lang>`.
* **pyasn1 advisories closed**: `requirements/seo.in` floors pyasn1 at 0.6.5 (GHSA-2qm8-x737-gmw5, GHSA-mm57-4v3p-rchx, GHSA-9m75-vc3g-4x39, GHSA-fm9c-5rcf-2q5p).
* **Stable required checks**: each versioned CI matrix gets a gate job, so branch protection survives Python, Node and Rust version bumps.
