Pain001 इंस्टॉल करें: pip, Docker और पहली सत्यापित फ़ाइल

Python 3.10–3.12, pip या Docker, और तीन कमांड में एक सत्यापित भुगतान फ़ाइल।

2 मिनट पठन अंतिम समीक्षा 2026-07-26

विषय-सूची

  1. PyPI
  2. Docker
  3. लॉक-डाउन वातावरण
  4. तीन कमांड में पहली फ़ाइल

Pain001 macOS, Linux और Windows पर Python 3.10, 3.11 और 3.12 (प्रत्येक संस्करण CI में परीक्षित) पर चलता है। जो चाहिए वही इंस्टॉल करें; हर वैकल्पिक क्षमता एक एक्स्ट्रा है, इसलिए बेस इंस्टॉल हल्का रहता है।

01. PyPI#

आपको क्या चाहिए कमांड
कोर CLI और Python लाइब्रेरी pip install pain001
REST API माइक्रोसर्विस (FastAPI + Uvicorn) pip install "pain001[api]"
Parquet इनजेशन (PyArrow) pip install "pain001[parquet]"
PGP-एन्क्रिप्टेड इनपुट फ़ाइलें (.gpg / .asc) pip install "pain001[gpg]"
API के लिए Redis-आधारित async जॉब कतार pip install "pain001[redis]"
OpenTelemetry ट्रेसिंग pip install "pain001[otel]"
बिल्ट-इन न्यूनतम MCP / LSP सर्वर pip install "pain001[mcp]" / "pain001[lsp]"

सहयोगी पैकेज अलग से इंस्टॉल होते हैं और स्वतंत्र रूप से संस्करणबद्ध हैं:

pip install pain001-loader-xlsx    # Excel ingestion (auto-discovered plugin)
pip install pain001-loader-mt101   # SWIFT MT101 parsing library
pip install pain001-mcp            # Full 17-tool MCP server for AI agents
pip install pain001-lsp            # Full six-feature editor language server

इंस्टॉल सत्यापित करें और संदेश कैटलॉग देखें:

pain001 --version
pain001 versions          # list all 11 supported message definitions
pain001 init pain.001.001.09   # scaffold a starter CSV template

02. Docker#

मल्टी-आर्किटेक्चर इमेज (linux/amd64, linux/arm64) GitHub Container Registry पर प्रकाशित होती हैं। कंटेनर एक समर्पित non-root उपयोगकर्ता के रूप में चलता है।

# Generate XML from a local CSV
docker run --rm -v "$PWD:/data" -w /data \
  ghcr.io/sebastienrousseau/pain001:latest \
  generate -t pain.001.001.09 -d payments.csv -o out/

# Launch the REST API
docker run --rm -p 8000:8000 \
  ghcr.io/sebastienrousseau/pain001:latest \
  serve --host 0.0.0.0 --port 8000

03. लॉक-डाउन वातावरण#

बैंक और ट्रेज़री वातावरण अक्सर डायनामिक प्लगइन लोडिंग निषिद्ध करते हैं। ठीक इसी स्थिति के लिए दो नियंत्रण मौजूद हैं:

  • PAIN001_DISABLE_PLUGINS=1 सभी तृतीय-पक्ष प्लगइन खोज अक्षम करता है; केवल बंडल किए गए लोडर चलते हैं।
  • pain001 plugins list / pain001 plugins show हर खोजे गए प्लगइन को प्रथम उपयोग से पहले ऑडिट-योग्य बनाते हैं।

सब कुछ स्थानीय रूप से चलता है। सुइट का कोई भी पैकेज बाहरी सर्वर से संपर्क नहीं करता, किसी SaaS API को कॉल नहीं करता, और भुगतान डेटा को होस्ट से बाहर नहीं ले जाता।

04. तीन कमांड में पहली फ़ाइल#

pip install pain001
pain001 init pain.001.001.09 -o work/
pain001 -t pain.001.001.09 -d work/template.csv -o work/ --dry-run

--dry-run आउटपुट लिखे बिना JSON Schema, XSD और (--scheme के साथ) SEPA या सीमा-पार नियमपुस्तिका के विरुद्ध सत्यापन करता है — एग्ज़िट कोड 0 का अर्थ है कि फ़ाइल उन जाँचों में उत्तीर्ण हुई: स्कीमा, और चयनित होने पर scheme नियमपुस्तिका। आपके बैंक की अपनी प्रोफ़ाइल और चैनल संबंधी नियम अलग हैं, और उनके लिए अब भी बैंक के साथ परीक्षण आवश्यक है। XML लिखने के लिए --dry-run हटा दें।

हर फ़्लैग और एंडपॉइंट के लिए तकनीकी संदर्भ पर जाएँ, या परिचालन प्रश्नों के लिए क्विकस्टार्ट FAQ देखें।
