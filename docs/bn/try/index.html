ইন্টারেক্টিভ ডেমো

আপনার ব্রাউজারে Pain001 ব্যবহার করে দেখুন

একটি CSV ফাইল ফেলুন, নমুনাটি ব্যবহার করুন বা নিজের রেকর্ড পেস্ট করুন — ভ্যালিডেশন তাৎক্ষণিকভাবে, সম্পূর্ণ আপনার ব্রাউজারে চলে, এবং কোনো কিছুই কখনো আপনার মেশিন ছেড়ে যায় না।

এই ভ্যালিডেটর আপনাকে কীভাবে সাহায্য করে

  • ✓ব্যাংকগুলি যে যাচাইগুলি প্রয়োগ করে সেগুলির বিপরীতে পেমেন্ট ডেটা পরীক্ষা করুন — আবশ্যিক ফিল্ড, IBAN চেকসাম, BIC কাঠামো, নিয়ন্ত্রণ যোগফল
  • ✓একটি কার্যকর pain.001.001.09 ক্রেডিট-ট্রান্সফার ফাইল তৈরি করুন যা আপনি পরীক্ষা, কপি বা ডাউনলোড করতে পারবেন
  • ✓ফলাফলটি অফিসিয়াল ISO 20022 স্কিমার বিপরীতে প্রমাণ করুন — আসল XSD, আপনার ব্রাউজারে যাচাইকৃত

গুরুত্বপূর্ণ তথ্য

  • কিছুই আপলোড হয় না। আপনার ফাইল আপনার নিজের ব্রাউজার পড়ে এবং তা কখনো আপনার মেশিন ছেড়ে যায় না — কোনো সার্ভার নেই, সংরক্ষণ নেই, টেলিমেট্রি নেই। প্রকৃত ডেটার জন্য নিরাপদ, তবে মাস্ক করা পরীক্ষার ডেটা সবসময়ই ভালো অভ্যাস।
  • শুধুই পরীক্ষার সরঞ্জাম। ফাইল কখনো প্রক্রিয়াকরণের জন্য জমা হয় না এবং এখানে আপনার কোনো কাজ থেকে কোনো পেমেন্ট হতে পারে না।
  • প্রত্যাশিত কলাম: payment_id, payment_amount, currency, দেনাদার ও পাওনাদারের নাম / IBAN / BIC, requested_execution_date — কমা, সেমিকোলন ও ট্যাব বিভাজক স্বয়ংক্রিয়ভাবে শনাক্ত হয়। নিজের এক্সপোর্টের টেমপ্লেট হিসেবে ব্যবহারের জন্য নিচে একটি নমুনা ডাউনলোড করুন।
  • কোনো চার্জ নেই। এই সরঞ্জাম এবং এর পেছনের সম্পূর্ণ টুলচেইন বিনামূল্যে ও ওপেন সোর্স।

নিজেই যাচাই করুন

"কিছুই আপলোড হয় না" এমন একটি দাবি যা আপনি দুই মিনিটে পরখ করতে পারেন:

  1. DevTools → Network খুলুন, তারপর ডেমোটি ব্যবহার করুন। একমাত্র অনুরোধগুলি হলো এই পৃষ্ঠার অ্যাসেট, WASM ইঞ্জিন ও স্কিমার জন্য একই-উৎসের GET — কোনোটিই আপনার ডেটা বহন করে না।
  2. XSD গেট একবার চালান, তারপর DevTools-কে Offline-এ নিন (বা Wi-Fi বন্ধ করুন)। সম্পূর্ণ ডেমো — অফিসিয়াল স্কিমা গেটসহ — তবুও কাজ করে: প্রথম ব্যবহারের পর একটি সার্ভিস ওয়ার্কার সবকিছু ক্যাশে রাখে।
  3. এই পৃষ্ঠাটিও ওপেন সোর্স — ডেমোর লজিক একটি নির্ভরতা-মুক্ত মডিউল যা আপনি সম্পূর্ণ পড়তে পারেন।

কোনো অ্যানালিটিক্স স্ক্রিপ্ট নেই, কোনো ত্রুটি-প্রতিবেদন পরিষেবা নেই, কোনো তৃতীয় পক্ষের ফন্ট নেই এবং কোনো CSP রিপোর্ট এন্ডপয়েন্ট নেই — প্রতিবেদন পাঠানো নিজেই একটি বহির্গামী সংযোগ হতো।

সর্বোচ্চ 2 MB · আপনার ব্রাউজার স্থানীয়ভাবে পড়ে, কখনো আপলোড হয় না

নিজের টেমপ্লেট হিসেবে ব্যবহারের জন্য একটি নমুনা ডাউনলোড করুন: SEPA ক্রেডিট ট্রান্সফার · আন্তঃসীমান্ত · 20-সারির ব্যাচ

3

অফিসিয়াল ISO 20022 XSD-এর বিপরীতে এটি প্রমাণ করুন

ধাপ 1–2 দ্রুত, হাতে লেখা যাচাই চালায়। এই ধাপটি আসল জিনিস চালায়: একটি Python রানটাইম (WebAssembly-এর মাধ্যমে) যা xmlschema অফিসিয়াল pain.001.001.09 স্কিমার বিপরীতে চালায় — CLI যে শ্রেণির ভ্যালিডেশন করে, ঠিক সেটিই। প্রায় 13 MB ইঞ্জিনটি এই সাইট থেকেই পরিবেশিত হয় এবং আপনি চাইলে একবারই ডাউনলোড হয় (ধাপ 2 বৈধ XML তৈরি করা মাত্রই এটি নিঃশব্দে ডাউনলোড শুরু হয়)।

আগে ধাপ 2-এ XML তৈরি করুন — XSD গেট সেই আউটপুট যাচাই করে।

    এই পৃষ্ঠার সবকিছু আপনার ব্রাউজারে চলে — কিছুই আপলোড, সংরক্ষণ বা কোথাও পাঠানো হয় না। এই ডেমো পাইপলাইনের একটি উপসেট বাস্তবায়ন করে (আবশ্যিক ফিল্ড, IBAN mod-97, BIC কাঠামো, পরিমাণ ও তারিখের বিন্যাস, পুনর্গণিত NbOfTxs/CtrlSum নিয়ন্ত্রণ যোগফল)। ধাপ 3 এখানেই WebAssembly-এর মাধ্যমে অফিসিয়াল XSD গেট চালায়। ইনস্টল করা টুলচেইন এর উপরে JSON Schema ভ্যালিডেশন ও পাঁচটি স্কিম নিয়মপুস্তক যোগ করে — সম্পূর্ণ পাইপলাইনের জন্য CLI ইনস্টল করুন।

    এই ডেমো কী দেখায় — এবং প্রকৃত পাইপলাইন কী যোগ করে

    প্রতিটি নমুনা ব্যাচ CSV ফাইল হিসেবেও ডাউনলোডযোগ্য, যাতে তা আপনার নিজের ERP বা স্প্রেডশিট এক্সপোর্টের টেমপ্লেট হয় — হেডার সারিটিই চুক্তি।

    উপরের ডেমো Pain001 পাইপলাইনের ফেল-ফাস্ট স্তর বাস্তবায়ন করে: আবশ্যিক-ফিল্ড যাচাই, ISO 13616 mod-97 IBAN চেকসাম, ISO 9362 BIC কাঠামো, পরিমাণ ও তারিখের বিন্যাস, এবং নিয়ন্ত্রণ যোগফল (NbOfTxs, CtrlSum) যা বিশ্বাস না করে রেকর্ড থেকে পুনর্গণনা করা হয়। "ত্রুটি যোগ করুন…" মেনুটি ব্যবহার করে দেখুন — প্রতিটি দৃশ্যকল্প ঠিক একটি বাস্তবসম্মত ত্রুটি বসায় (উল্টানো IBAN অঙ্ক, বিকৃত BIC, অনুপস্থিত কলাম, ইউরোপীয় কমা-দশমিক পরিমাণ, অসম্ভব তারিখ) এবং সেই সারি-স্তরের ফলাফল দেখায় যা ব্যাংকের গেটওয়ে নাহলে কয়েক দিন পরে জানাত।

    ইনস্টল করা টুলচেইন অনেক গভীর গেট চালায়: ফিল্ড-উপনাম স্বাভাবিকীকরণসহ প্রতিটি রেকর্ডের JSON Schema ভ্যালিডেশন, নিয়ম-ধরে-নিয়ম --explain আউটপুটসহ পাঁচটি স্কিম নিয়মপুস্তক (SEPA SCT, Instant, SDD Core, B2B, আন্তঃসীমান্ত), এবং একটি বাইটও লেখার আগে প্রস্তুত নথির অফিসিয়াল ISO 20022 XSD-এর বিপরীতে চূড়ান্ত যাচাই। দশটি pain.001 সংস্করণ এবং pain.008.001.02 সমর্থিত।

    pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --scheme sepa-sct --dry-run

    উপরের ধাপ 3 কোনো সিমুলেশন নয়: এটি WebAssembly-তে একটি Python রানটাইম চালু করে এবং xmlschema-কে অফিসিয়াল pain.001.001.09 স্কিমার বিপরীতে চালায়, যা এই সাইট থেকেই পরিবেশিত — CLI যে শ্রেণির XSD গেট প্রয়োগ করে, ঠিক সেটিই। যা কেবল CLI-তে থাকে তা হলো পাইপলাইনের বাকিটা: JSON Schema স্বাভাবিকীকরণ, --explain-সহ পাঁচটি স্কিম নিয়মপুস্তক, এবং অন্য দশটি বার্তা সংজ্ঞা।
