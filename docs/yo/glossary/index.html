Àkójọ ìtumọ̀

Àkójọ Ìtumọ̀ Ọ̀rọ̀ Ìsanwó ISO 20022 ní Èdè Rírọrùn

Àwọn ọ̀rọ̀ ìsanwó ní èdè rírọrùn — fún àwọn tí ó ń fọwọ́sí fáìlì, kì í ṣe fún àwọn tí ó ń ṣẹ̀dá wọn nìkan.

3 ìṣẹ́jú kíkà Àyẹ̀wò tó kẹ́yìn 2026-07-26

Àkóónú

  1. Àwọn ìránṣẹ́
  2. Àwọn ètò àti ìwé òfin
  3. Àwọn ìdámọ̀ àti dátà
  4. Àwọn ọ̀rọ̀ irinṣẹ́ tí a lò lórí ojú-ìwé yìí

Ìtumọ̀ rírọrùn fún àwọn ọ̀rọ̀ tí ó farahàn káàkiri ojú-ìwé yìí àti nínú àkọsílẹ̀ ọ̀nà báńkì yín. A kọ ọ́ fún àwọn olùṣàkóso ìṣúna àti ẹgbẹ́ òṣìṣẹ́ ní àkọ́kọ́, fún àwọn ẹnjinnià ní ẹ̀ẹ̀kejì.

Àwọn ìránṣẹ́#

pain.001 — Customer Credit Transfer Initiation. Ìránṣẹ́ XML tí oníbàárà ń fi ránṣẹ́ sí báńkì rẹ̀ láti pàṣẹ ìfiránṣẹ́ owó kan tàbí jù bẹ́ẹ̀ lọ. Ìdílé "pain" túmọ̀ sí ìbẹ̀rẹ̀ ìsanwó; .001 ni nọ́ḿbà ìránṣẹ́ náà; ẹ̀yà tí ó tẹ̀lé e (.001.09) ni ó so schema náà mọ́lẹ̀.

pain.002 — Customer Payment Status Report. Ìdáhùn báńkì sí pain.001 tàbí pain.008 yín: a gbà á, a gbà á ní apá kan, tàbí a kọ̀ ọ́, pẹ̀lú kóòdù ìdí ISO fún ìdúnàádúrà kọ̀ọ̀kan.

pain.008 — Customer Direct Debit Initiation. Ìbejì pain.001 ní apá ìgbà owó: ẹ ń gba owó tí wọ́n jẹ yín lábẹ́ àṣẹ ìfàṣẹ́sí dípò kí ẹ fi owó ránṣẹ́ jáde.

pacs.008 / pacs.009. Àwọn ìránṣẹ́ ìsanwó láàrin àwọn báńkì tí àṣẹ yín yóò di lẹ́yìn tí báńkì bá gbà á. Àwọn ilé-iṣẹ́ kì í kọ ìwọ̀nyí; àwọn báńkì ni wọ́n ń pàrọ̀ wọn.

camt.052 / camt.053 / camt.054. Ìròyìn àkọọ́lẹ̀: ìròyìn àárín ọjọ́, ìsọ̀rọ̀ òpin ọjọ́, àti ìfitónilétí ìyọkúrò tàbí ìfikún owó lẹ́sẹẹsẹ. camt.053 ni ohun tí àwọn ẹgbẹ́ ìbáradọ́gba ń lò ní àárọ̀ kọ̀ọ̀kan.

MT101. Ìránṣẹ́ ọ̀rọ̀ SWIFT àtijọ́ "Request for Transfer" tí pain.001 ń rọ́pò. A ó dá ìfiránṣẹ́ MT101 láàrin àwọn báńkì dúró ní 14 November 2026 fún pain.001.001.09; MT101 láti ilé-iṣẹ́ sí báńkì yóò máa wà lábẹ́ ìpinnu báńkì kọ̀ọ̀kan nìkan.

Àwọn ètò àti ìwé òfin#

SEPA SCT / SCT Inst. Àwọn ètò ìfiránṣẹ́ owó Yúrò (àbáyọ déédéé àti ojúkojú) tí àwọn ìwé òfin European Payments Council ń ṣàkóso. Ìfiránṣẹ́ ojúkojú ń parí láàrin ìṣẹ́jú-àáyá, ní gbogbo ìgbà.

SEPA SDD Core / B2B. Àwọn ètò ìgbà owó tààrà ní Yúrò — Core fún àwọn oníbàárà (pẹ̀lú ẹ̀tọ́ ìpadàbọ̀ owó), B2B fún àwọn ilé-iṣẹ́ (kò sí ẹ̀tọ́ ìpadàbọ̀ owó, àyẹ̀wò àṣẹ sì le sí i).

CBPR+. Cross-Border Payments and Reporting Plus: àwọn ìtọ́sọ́nà ìlò tí ó ń ṣe àpèjúwe àwọn ìránṣẹ́ ISO 20022 fún ìfọwọ́sowọ́pọ̀ báńkì SWIFT. Nígbà tí àwọn ènìyàn bá sọ "ìyípadà SWIFT sí ISO 20022", CBPR+ ni wọ́n ń sọ.

HVPS+. Àpèjúwe kan náà fún àwọn ètò ìsanwó oníyeye ńlá (T2, CHAPS, Fedwire àti àwọn ẹgbẹ́ wọn).

CGI-MP. Common Global Implementation — Market Practice: ẹgbẹ́ tí ó ń mú bí àwọn ilé-iṣẹ́ ṣe ń lo àwọn ìránṣẹ́ pain káàkiri àwọn báńkì dọ́gba, kí ìlànà fáìlì kan ṣoṣo lè bá ọ̀pọ̀ alábàáṣepọ̀ báńkì mu.

Verification of Payee (VoP). Àyẹ̀wò ìbámu orúkọ àti IBAN tí EU pàṣẹ fún gbogbo ìfiránṣẹ́ owó SEPA láti 9 October 2025. PSP ni ó ń ṣe é ní àkókò ìṣiṣẹ́; dátà onígbèsè mímọ́ ni ó ń pinnu bóyá yóò bá a mu.

Àwọn ìdámọ̀ àti dátà#

IBAN. Nọ́ḿbà Àkọọ́lẹ̀ Báńkì Àgbáyé (ISO 13616), tí ó ń ṣàyẹ̀wò ara rẹ̀ nípasẹ̀ checksum mod-97 — ìdí nìyí tí a fi lè rí ìpààrọ̀ nọ́ḿbà kan ṣoṣo ṣáájú ìfisílẹ̀.

BIC / BICFI. Kóòdù Ìdámọ̀ Òwò ISO 9362 ti ilé-iṣẹ́ ìnáwó kan. Ẹ̀yà XML náà ni nínú pain.001.001.03 ṣùgbọ́n láti ẹ̀yà 9 — ìyípadà orúkọ tí ó ń fa ìkọ̀sílẹ̀ gidi nígbà ìgbésókè ẹ̀yà.

LEI. Ìdámọ̀ Ilé-iṣẹ́ Lábẹ́ Òfin (ISO 17442) — ìdámọ̀ ilé-iṣẹ́ àgbáyé onílẹ́tà 20. Ó ju mílíọ̀nù 3 tí ó ń ṣiṣẹ́ lọ, àwọn alábòójútó òfin sì ń pàṣẹ wọn sí i nínú ìsanwó.

UETR. Ìtọ́kasí Ìdúnàádúrà Àrà-ọ̀tọ̀ láti Ìbẹ̀rẹ̀ dé Òpin — UUID tí ó ń jẹ́ kí a lè tọpinpin ìsanwó káàkiri ẹ̀wọ̀n àwọn báńkì alábàáṣepọ̀ (SWIFT gpi).

Àdírẹ́sì onílànà / àdàpọ̀. Àwọn àdírẹ́sì ìfìwéránṣẹ́ gẹ́gẹ́ bí ẹ̀yà XML ọ̀tọ̀ọ̀tọ̀ (òpópónà, ìlú, kóòdù ìfìwéránṣẹ́, orílẹ̀-èdè) dípò àwọn ìlà ọ̀rọ̀ ọ̀fẹ́. Láti 14 November 2026, CBPR+ ń kọ àwọn àdírẹ́sì tí kò ní ìlànà rárá; àdàpọ̀ — ìlú àti orílẹ̀-èdè onílànà pẹ̀lú ìlà àdírẹ́sì méjì tí ó ní lẹ́tà 70 — ṣì tọ́.

NbOfTxs / CtrlSum. Àpapọ̀ ìdarí ní orí àkójọ: iye ìdúnàádúrà àti àpapọ̀ owó. Àwọn báńkì ń tún ṣírò wọn; bí tiyín kò bá bá a mu, fáìlì náà yóò padà. Pain001 ń rí wọn gbà nígbà gbogbo láti inú àwọn àkọsílẹ̀ tí a ti ṣàyẹ̀wò.

Ẹni tí ó ń san owó iṣẹ́. Ẹni tí ó ń san owó iṣẹ́: DEBT (olùfiránṣẹ́), CRED (olùgbà), SHAR (pínpín), SLEV (gẹ́gẹ́ bí òfin ètò). MT àtijọ́ OUR/BEN/SHA bá mẹ́ta àkọ́kọ́ mu.

Ìsọfúnni ìsanwó. Pápá "kí ni ìsanwó yìí fún" — ọ̀rọ̀ ọ̀fẹ́ (lẹ́tà 140) tàbí ìtọ́kasí onílànà. Ohun tí àwọn ẹgbẹ́ ìbáradọ́gba ń fẹ́ kí gbogbo ènìyàn kún dáadáa.

Àwọn ọ̀rọ̀ irinṣẹ́ tí a lò lórí ojú-ìwé yìí#

Ìṣàyẹ̀wò XSD. Ṣíṣàyẹ̀wò XML lòdì sí ìtumọ̀ schema ISO 20022 òṣìṣẹ́. Pain001 ń kà á sí ẹnu-ọ̀nà líle kí a tó kọ fáìlì kankan.

MCP — Model Context Protocol. Ìlànà ṣíṣí tí àwọn olùrànlọ́wọ́ AI ń lò láti pe àwọn irinṣẹ́ ìta. pain001-mcp ń fi irinṣẹ́ ìsanwó 17 hàn fún gbogbo oníbàárà MCP, ní agbègbè rẹ̀ nípasẹ̀ stdio.

LSP — Language Server Protocol. Ìlànà ìsopọ̀ olùṣàtúnṣe tí ó wà lẹ́yìn àwọn ìtọ́kasí àṣìṣe nínú IDE. pain001-lsp ń lò ó láti ṣàyẹ̀wò àwọn fáìlì ìsanwó bí ẹ ṣe ń tẹ̀wé.

SBOM. Àkójọ Ohun Èlò Sọ́fítíwéà — àkójọ tí ẹ̀rọ lè kà nípa gbogbo ìgbáralé nínú ìtújáde kan, tí a ṣẹ̀dá ní ìlànà CycloneDX fún àwọn ìtújáde ìpìlẹ̀ Pain001.

Ǹjẹ́ ohun kan kù? Ẹ dábàá ọ̀rọ̀ kan — àkójọ ìtumọ̀ yìí ń dàgbà pẹ̀lú àwọn ìbéèrè tí àwọn ènìyàn ń bèèrè ní ti gidi.
