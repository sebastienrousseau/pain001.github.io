Àfihàn ìbáṣepọ̀

Gbìyànjú Pain001 Nínú Aṣàwákiri Yín

Ẹ fi fáìlì CSV sínú rẹ̀, ẹ lo àpẹẹrẹ, tàbí kí ẹ lẹ àwọn àkọsílẹ̀ yín — àyẹ̀wò ń ṣiṣẹ́ lẹ́sẹ̀kẹsẹ̀, pátápátá nínú aṣàwákiri yín, kò sì sí ohunkóhun tí yóò kúrò ní ẹ̀rọ yín láé.

Bí ohun-èlò àyẹ̀wò yìí ṣe ń ràn yín lọ́wọ́

  • ✓Ẹ dán dátà ìsanwó wò lórí àwọn àyẹ̀wò tí àwọn báńkì ń lò — àwọn àyè dandan, àyẹ̀wò ìṣirò IBAN, ìhun BIC, àpapọ̀ ìṣàkóso
  • ✓Ẹ ṣẹ̀dá fáìlì pain.001.001.09 ìfowóránṣẹ́ tí ó ń ṣiṣẹ́, tí ẹ lè ṣàyẹ̀wò, ṣe àdàkọ, tàbí gbà sílẹ̀
  • ✓Ẹ fi ìdí àbájáde múlẹ̀ lórí ìlànà (schema) ISO 20022 ti àṣẹ — XSD tòótọ́, tí a ń yẹ̀ wò nínú aṣàwákiri yín

Àlàyé pàtàkì

  • A kò gbé ohunkóhun sórí ayélujára. Aṣàwákiri yín fúnra rẹ̀ ni ó ń ka fáìlì yín, kò sì kúrò ní ẹ̀rọ yín láé — kò sí sáfà, kò sí ìfipamọ́, kò sí ìránṣẹ́ dátà. Ó ní ààbò fún dátà gidi, ṣùgbọ́n lílo dátà ìdánwò tí a bò ṣì jẹ́ àṣà rere nígbà gbogbo.
  • Ohun-èlò ìdánwò nìkan ni. A kì í fi àwọn fáìlì ránṣẹ́ fún ìṣesí kankan, kò sì sí ìsanwó kankan tí ó lè wáyé láti ara ohunkóhun tí ẹ bá ṣe níbí.
  • Àwọn ọ̀wọ̀n tí a retí: payment_id, payment_amount, currency, orúkọ ẹni tí ó ń sanwó àti ẹni tí ó ń gbà / IBAN / BIC, requested_execution_date — a máa ń dá àmì ìyàsọ́tọ̀ kọ́mà, sẹ́mikólọ́nì àti tab mọ̀ fúnra rẹ̀. Ẹ gba àpẹẹrẹ sílẹ̀ nísàlẹ̀ láti lò gẹ́gẹ́ bí àwòṣe fún ìgbéjáde tiyín.
  • Kò sí owó kankan. Ohun-èlò yìí, àti gbogbo àkójọ irinṣẹ́ tí ó wà lẹ́yìn rẹ̀, jẹ́ ọ̀fẹ́, orísun-ìṣí ni wọ́n sì jẹ́.

Ẹ fi ìdí rẹ̀ múlẹ̀ fúnra yín

"A kò gbé ohunkóhun sórí ayélujára" jẹ́ ọ̀rọ̀ tí ẹ lè dán wò ní ìṣẹ́jú méjì:

  1. Ẹ ṣí DevTools → Network, kí ẹ sì lo àfihàn náà. Àwọn ìbéèrè kan ṣoṣo tí ó wà ni àwọn GET orísun-kannáà fún àwọn ohun-èlò ojú-ìwé yìí, ẹ́ńjìnnì WASM, àti ìlànà (schema) náà — kò sí èyí tí ó gbé dátà yín.
  2. Ẹ ṣiṣẹ́ ẹnu-bodè XSD lẹ́ẹ̀kan, lẹ́yìn náà kí ẹ yí DevTools sí Offline (tàbí kí ẹ pa Wi-Fi). Gbogbo àfihàn náà — pẹ̀lú ẹnu-bodè ìlànà ti àṣẹ — ṣì ń ṣiṣẹ́: service worker kan máa ń tọ́jú ohun gbogbo pamọ́ lẹ́yìn ìlò àkọ́kọ́.
  3. Ojú-ìwé yìí pẹ̀lú jẹ́ orísun-ìṣí — ọ̀nà-iṣẹ́ àfihàn náà jẹ́ mọ́díùlù kan ṣoṣo tí kò gbára lé ohunkóhun, tí ẹ lè kà ní kíkún.

Kò sí ìwé-àfọwọ́kọ ìtúpalẹ̀, kò sí iṣẹ́ ìròyìn àṣìṣe, kò sí fọ́ǹtì ẹnìkẹta, kò sì sí ojú-ìsopọ̀ ìròyìn CSP — ìròyìn fúnra rẹ̀ ìbá jẹ́ ìsopọ̀ síta.

Ẹ fi ìdí rẹ̀ múlẹ̀ lórí XSD ISO 20022 ti àṣẹ

Àwọn ìgbésẹ̀ 1–2 ń ṣiṣẹ́ àyẹ̀wò kíákíá tí a fi ọwọ́ kọ. Ìgbésẹ̀ yìí ń ṣiṣẹ́ ohun gidi náà: runtime Python kan (nípasẹ̀ WebAssembly) tí ó ń mú xmlschema ṣiṣẹ́ lórí ìlànà pain.001.001.09 ti àṣẹ — irú àyẹ̀wò kannáà tí CLI ń ṣe. Láti orí ojú-ìwé yìí ni a ti ń pèsè ẹ́ńjìnnì ~13 MB náà, a sì ń gbà á sílẹ̀ lẹ́ẹ̀kan ṣoṣo, nígbà tí ẹ bá béèrè fún un (ó máa ń bẹ̀rẹ̀ sí í gbà sílẹ̀ jẹ́ẹ́jẹ́ ní kété tí ìgbésẹ̀ 2 bá ti ṣẹ̀dá XML tí ó yẹ).

Ẹ kọ́kọ́ ṣẹ̀dá XML ní ìgbésẹ̀ 2 — àbájáde yẹn ni ẹnu-bodè XSD ń yẹ̀ wò.

    Gbogbo ohun tí ó wà lórí ojú-ìwé yìí ń ṣiṣẹ́ nínú aṣàwákiri yín — a kò gbé ohunkóhun sókè, a kò fi pamọ́, a kò sì fi ránṣẹ́ sí ibìkankan. Àfihàn yìí ń ṣe apá kan nínú ọ̀nà-iṣẹ́ náà (àwọn àyè dandan, IBAN mod-97, ìhun BIC, ìgbékalẹ̀ iye owó àti ọjọ́, àpapọ̀ ìṣàkóso NbOfTxs/CtrlSum tí a tún ṣírò). Ìgbésẹ̀ 3 ń ṣiṣẹ́ ẹnu-bodè XSD ti àṣẹ níbí gan-an nípasẹ̀ WebAssembly. Àkójọ irinṣẹ́ tí a fi sórí ẹ̀rọ ń fi àyẹ̀wò JSON Schema àti ìwé òfin ìlànà márùn-ún kún un — ẹ fi CLI sórí ẹ̀rọ fún gbogbo ọ̀nà-iṣẹ́ ní kíkún.

    Ohun tí àfihàn yìí fi hàn — àti ohun tí ọ̀nà-iṣẹ́ gidi ń fi kún un

    Àkójọ àpẹẹrẹ kọ̀ọ̀kan tún jẹ́ èyí tí a lè gbà sílẹ̀ gẹ́gẹ́ bí fáìlì CSV láti lò gẹ́gẹ́ bí àwòṣe fún ìgbéjáde ERP tàbí spreadsheet tiyín — ìlà àkọlé ni àdéhùn náà.

    Àfihàn tí ó wà lókè ń ṣe ìpele ìkùnà-kíákíá ti ọ̀nà-iṣẹ́ Pain001: àyẹ̀wò àwọn àyè dandan, àyẹ̀wò ìṣirò IBAN mod-97 ti ISO 13616, ìhun BIC ti ISO 9362, ìgbékalẹ̀ iye owó àti ọjọ́, àti àpapọ̀ ìṣàkóso (NbOfTxs, CtrlSum) tí a tún ṣírò láti ara àwọn àkọsílẹ̀ dípò kí a gbà wọ́n gbọ́ lásán. Ẹ dán àtòjọ "Ẹ ṣàfihàn àṣìṣe kan…" wò — ipò kọ̀ọ̀kan máa ń gbin àléébù gidi kan ṣoṣo (nọ́ńbà IBAN tí a yí padà, BIC tí kò tọ̀nà, ọ̀wọ̀n tí ó sọnù, iye owó kọ́mà-décímàlì ti Yúróòpù, ọjọ́ tí kò ṣeé ṣe) yóò sì fi àbájáde ìlà-kọ̀ọ̀kan hàn yín, èyí tí ẹnu-bodè báńkì ìbá ròyìn rẹ̀ lẹ́yìn ọjọ́ púpọ̀.

    Àkójọ irinṣẹ́ tí a fi sórí ẹ̀rọ ń ṣiṣẹ́ ẹnu-bodè tí ó jinlẹ̀ púpọ̀: àyẹ̀wò JSON Schema fún àkọsílẹ̀ kọ̀ọ̀kan pẹ̀lú ìṣàtúnṣe orúkọ-àyè, ìwé òfin ìlànà márùn-ún (SEPA SCT, Instant, SDD Core, B2B, ìkọjá-ààlà) pẹ̀lú àbájáde --explain òfin-lẹ́yìn-òfin, àti àyẹ̀wò ìkẹyìn ti ìwé tí a ṣẹ̀dá lórí XSD ISO 20022 ti àṣẹ kí a tó kọ báìtì kan ṣoṣo. Ó ń ti ẹ̀yà pain.001 mẹ́wàá àti pain.008.001.02 lẹ́yìn.

    pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --scheme sepa-sct --dry-run

    Ìgbésẹ̀ 3 tí ó wà lókè kì í ṣe àfarawé: ó ń tan runtime Python kan nínú WebAssembly, ó sì ń ṣiṣẹ́ xmlschema lórí ìlànà pain.001.001.09 ti àṣẹ, tí a ń pèsè láti orí ojú-ìwé yìí — irú ẹnu-bodè XSD kannáà tí CLI ń lò. Ohun tí ó ṣẹ́ kù fún CLI nìkan ni ìyókù ọ̀nà-iṣẹ́ náà: ìṣàtúnṣe JSON Schema, ìwé òfin ìlànà márùn-ún pẹ̀lú --explain, àti àwọn ìtumọ̀ ìránṣẹ́ mẹ́wàá yòókù.
