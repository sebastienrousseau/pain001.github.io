# 1. Install Pain001 Suite
pip install pain001 pain001-loader-xlsx pain001-loader-mt101 pain001-mcp

Frequently Asked Questions

Answers for Treasurers, CFOs, Enterprise Architects, and Integration Engineers.

Banks reject malformed payment files due to schema mismatch, monetary rounding errors, or improper control totals. Pain001 ingests standard data exports (CSV, Excel, SQLite, JSON, Parquet, MT101) and generates 100% XSD-validated ISO 20022 XML files before submission to the bank.
Pain001 supports all versions from pain.001.001.03 up to pain.001.001.12 and pain.008.001.02 through .10. It includes schema rules for SEPA SCT, SEPA Instant, SEPA Direct Debit, and SWIFT CBPR+ cross-border mandates, including the November 2026 mandatory Structured Address requirements.
pain001-mcp exposes 17 dedicated tools to AI agents (such as Claude Desktop, Cursor, and custom LLM orchestrators). AI agents can perform pre-flight checks, validate IBAN/BICs, transliterate ISO 20022 charsets, migrate records across message versions, and trigger payment file generation directly within conversational workflows.
Yes. Pain001 enforces exact monetary precision using Python's decimal.Decimal to prevent floating-point rounding errors, protects against XML External Entity (XXE) attacks using defusedxml, automatically calculates control totals (NbOfTxs, CtrlSum), runs non-root inside container images, and provides memory-bounded streaming for multi-gigabyte payment batches.
