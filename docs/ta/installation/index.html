Pain001 நிறுவல்: pip, Docker, முதல் சரிபார்க்கப்பட்ட கோப்பு

Python 3.10–3.12, pip அல்லது Docker, மூன்று கட்டளைகளில் சரிபார்க்கப்பட்ட ஒரு பணப்பரிவர்த்தனைக் கோப்பு.

2 நிமிட வாசிப்பு கடைசி மதிப்பாய்வு 2026-07-26

பொருளடக்கம்

  1. PyPI
  2. Docker
  3. கட்டுப்படுத்தப்பட்ட சூழல்கள்
  4. மூன்று கட்டளைகளில் முதல் கோப்பு

Pain001 ஆனது macOS, Linux, Windows ஆகியவற்றில் Python 3.10, 3.11, 3.12 பதிப்புகளில் இயங்குகிறது (ஒவ்வொரு பதிப்பும் CI-இல் சோதிக்கப்படுகிறது). உங்களுக்குத் தேவையானதை மட்டும் நிறுவுங்கள்; ஒவ்வொரு விருப்பத் திறனும் ஒரு கூடுதலாக இருப்பதால் அடிப்படை நிறுவல் இலகுவாகவே இருக்கிறது.

01. PyPI#

உங்களுக்குத் தேவையானது கட்டளை
மைய CLI மற்றும் Python நூலகம் pip install pain001
REST API நுண்சேவை (FastAPI + Uvicorn) pip install "pain001[api]"
Parquet உள்வாங்கல் (PyArrow) pip install "pain001[parquet]"
PGP-குறியாக்கப்பட்ட உள்ளீட்டுக் கோப்புகள் (.gpg / .asc) pip install "pain001[gpg]"
API-க்கான Redis அடிப்படையிலான ஒத்திசைவற்ற பணி வரிசை pip install "pain001[redis]"
OpenTelemetry தடமறிதல் pip install "pain001[otel]"
உள்ளமைந்த குறைந்தபட்ச MCP / LSP சேவையகங்கள் pip install "pain001[mcp]" / "pain001[lsp]"

துணைப் பொதிகள் தனித்தனியாக நிறுவப்படுகின்றன, தனித்தனியாகவே பதிப்பிடப்படுகின்றன:

pip install pain001-loader-xlsx    # Excel ingestion (auto-discovered plugin)
pip install pain001-loader-mt101   # SWIFT MT101 parsing library
pip install pain001-mcp            # Full 17-tool MCP server for AI agents
pip install pain001-lsp            # Full six-feature editor language server

நிறுவலைச் சரிபார்த்து, செய்திப் பட்டியலை ஆராயுங்கள்:

pain001 --version
pain001 versions          # list all 11 supported message definitions
pain001 init pain.001.001.09   # scaffold a starter CSV template

02. Docker#

பல-கட்டமைப்புப் படிமங்கள் (linux/amd64, linux/arm64) GitHub Container Registry-இல் வெளியிடப்படுகின்றன. கன்டெய்னர் தனிப்பட்ட, ரூட் அல்லாத பயனராக இயங்குகிறது.

# Generate XML from a local CSV
docker run --rm -v "$PWD:/data" -w /data \
  ghcr.io/sebastienrousseau/pain001:latest \
  generate -t pain.001.001.09 -d payments.csv -o out/

# Launch the REST API
docker run --rm -p 8000:8000 \
  ghcr.io/sebastienrousseau/pain001:latest \
  serve --host 0.0.0.0 --port 8000

03. கட்டுப்படுத்தப்பட்ட சூழல்கள்#

வங்கி மற்றும் கருவூலச் சூழல்கள் பெரும்பாலும் இயங்குநேரச் செருகுநிரல் ஏற்றத்தைத் தடை செய்கின்றன. அத்தகைய சூழலுக்காகவே இரு கட்டுப்பாடுகள் உள்ளன:

  • PAIN001_DISABLE_PLUGINS=1 மூன்றாம் தரப்புச் செருகுநிரல் கண்டறிதல் அனைத்தையும் முடக்குகிறது; உள்ளடக்கப்பட்ட லோடர்கள் மட்டுமே இயங்கும்.
  • pain001 plugins list / pain001 plugins show <name> கண்டறியப்பட்ட ஒவ்வொரு செருகுநிரலையும் முதல் பயன்பாட்டுக்கு முன்பே தணிக்கை செய்யக்கூடியதாக்குகின்றன.

அனைத்தும் உள்ளூரிலேயே இயங்குகின்றன. இத்தொகுப்பில் உள்ள எந்தப் பொதியும் வெளியே தகவல் அனுப்புவதில்லை, SaaS API-ஐ அழைப்பதில்லை, பணப்பரிவர்த்தனைத் தரவை ஹோஸ்டை விட்டு வெளியே நகர்த்துவதில்லை.

04. மூன்று கட்டளைகளில் முதல் கோப்பு#

pip install pain001
pain001 init pain.001.001.09 -o work/
pain001 -t pain.001.001.09 -d work/template.csv -o work/ --dry-run

--dry-run வெளியீட்டை எழுதாமலேயே JSON Schema, XSD, மேலும் (--scheme உடன்) ஒரு SEPA அல்லது எல்லை கடந்த விதிநூல் ஆகியவற்றுக்கு எதிராகச் சரிபார்க்கிறது — வெளியேற்றக் குறியீடு 0 என்றால் அந்தக் கோப்பு அந்தச் சரிபார்ப்புகளில் தேறியுள்ளது என்று அர்த்தம்: ஸ்கீமா, மேலும் தேர்ந்தெடுக்கப்பட்டிருந்தால் scheme விதிநூல். உங்கள் வங்கியின் சொந்த சுயவிவரம் மற்றும் சேனல் விதிகள் தனியானவை; அவற்றுக்கு இன்னும் வங்கியுடன் சோதனை தேவை. XML-ஐ எழுத --dry-run ஐ நீக்குங்கள்.

ஒவ்வொரு ஃபிளாக் மற்றும் எண்ட்பாயிண்டுக்கும் தொழில்நுட்பக் குறிப்புக்குச் செல்லுங்கள், அல்லது செயல்பாட்டுக் கேள்விகளுக்கு விரைவுத் தொடக்க FAQ ஐப் பார்வையிடுங்கள்.
