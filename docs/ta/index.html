Pain001 — திறந்த மூல ISO 20022 கட்டணத் தொடக்கம்

உங்கள் கட்டணத் தரவை சரிபார்க்கப்பட்ட ISO 20022 XML ஆக மாற்றும் திறந்த மூல தொகுப்பு — வங்கியை அடையும் முன்பே சரியென நிரூபிக்கப்பட்டது.

1 min read Last reviewed 26 July 2026

உங்கள் வங்கி நிராகரிக்காத கட்டணக் கோப்புகள்#

Pain001 என்பது ISO 20022 கட்டணத் தொடக்கத்திற்கான திறந்த மூல Python தொகுப்பு. உங்களிடம் ஏற்கனவே உள்ள தரவை — CSV, Excel, SQLite, JSON, Parquet அல்லது பழைய SWIFT MT101 செய்திகள் — அதிகாரப்பூர்வ XSD ஸ்கீமாக்களால் சரிபார்க்கப்பட்ட pain.001 (கடன் பரிமாற்றம்) மற்றும் pain.008 (நேரடி பற்று) XML ஆக மாற்றுகிறது.

ஒவ்வொரு கோப்பும் எழுதப்படும் முன் மூன்று சரிபார்ப்பு அடுக்குகளைக் கடக்கிறது: ஒவ்வொரு பதிவுக்கும் JSON ஸ்கீமா (IBAN mod-97 சோதனை மற்றும் BIC அமைப்பு உட்பட), scheme விதிகள் (SEPA மற்றும் எல்லை கடந்த CBPR+), இறுதி XSD சரிபார்ப்பு. கட்டுப்பாட்டு மொத்தங்கள் மீண்டும் கணக்கிடப்படுகின்றன, ஒருபோதும் நகலெடுக்கப்படுவதில்லை. அனைத்தும் உள்ளூரில் இயங்கும்: எந்தக் கட்டணத் தரவும் உங்கள் உள்கட்டமைப்பை விட்டு வெளியேறாது.

14 நவம்பர் 2026 காலக்கெடு#

22 நவம்பர் 2025 இல் MT–MX இணைவாழ்வு முடிந்த பின், அடுத்த காலக்கெடு 14 நவம்பர் 2026: முழுமையாக கட்டமைக்கப்படாத அஞ்சல் முகவரிகள் CBPR+ கட்டணங்களில் நிராகரிக்கப்படும்; வங்கிகளிடையேயான MT101 ரிலேவுக்குப் பதிலாக pain.001 பதிப்பு 9 வரும். Pain001 இன்றே கட்டமைக்கப்பட்ட மற்றும் கலப்பு முகவரிகளை உருவாக்குகிறது — ஒரே கட்டளையில் MT101 ஐ மாற்றுகிறது.

தொடங்குங்கள்#

pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --dry-run

முழு ஆவணங்கள் ஆங்கிலத்தில்: நிறுவல் வழிகாட்டி, தொழில்நுட்பக் குறிப்பு, உலாவி டெமோ மற்றும் 2026 ISO 20022 விளக்கம். மையம் Apache-2.0 / MIT இரட்டை உரிமத்தில் — எந்த அளவிலும் இலவச வணிகப் பயன்பாடு.
