ஊடாடும் செயல்விளக்கம்

Pain001-ஐ உங்கள் உலாவியில் முயற்சிக்கவும்

ஒரு CSV கோப்பை இடவும், மாதிரியைப் பயன்படுத்தவும் அல்லது உங்கள் சொந்தப் பதிவுகளை ஒட்டவும் — சரிபார்ப்பு உடனடியாக, முழுவதுமாக உங்கள் உலாவியிலேயே இயங்கும்; எதுவும் உங்கள் கணினியை விட்டு வெளியேறாது.

இந்தச் சரிபார்ப்புக் கருவி உங்களுக்கு எவ்வாறு உதவுகிறது

  • ✓வங்கிகள் பயன்படுத்தும் சோதனைகளுக்கு எதிராகப் பணம் செலுத்தும் தரவைச் சோதிக்கவும் — தேவையான புலங்கள், IBAN சரிகாண் தொகைகள், BIC அமைப்பு, கட்டுப்பாட்டு மொத்தங்கள்
  • ✓நீங்கள் ஆய்வு செய்யவோ, நகலெடுக்கவோ அல்லது பதிவிறக்கவோ கூடிய, செயல்படும் pain.001.001.09 கடன்-பரிமாற்றக் கோப்பை உருவாக்கவும்
  • ✓அதிகாரப்பூர்வ ISO 20022 திட்ட வரைவுக்கு எதிராக முடிவை நிரூபிக்கவும் — உண்மையான XSD, உங்கள் உலாவியிலேயே சரிபார்க்கப்படுகிறது

முக்கியத் தகவல்

  • எதுவும் பதிவேற்றப்படுவதில்லை. உங்கள் கோப்பு உங்கள் சொந்த உலாவியால் மட்டுமே படிக்கப்படுகிறது; அது ஒருபோதும் உங்கள் கணினியை விட்டு வெளியேறாது — சேவையகம் இல்லை, சேமிப்பு இல்லை, தொலைநிலை அளவீடு இல்லை. உண்மையான தரவுக்கும் பாதுகாப்பானது; இருப்பினும் மறைக்கப்பட்ட சோதனைத் தரவைப் பயன்படுத்துவது எப்போதும் நல்ல நடைமுறை.
  • சோதனைக் கருவி மட்டுமே. கோப்புகள் ஒருபோதும் செயலாக்கத்திற்குச் சமர்ப்பிக்கப்படுவதில்லை; இங்கு நீங்கள் செய்யும் எதனாலும் எந்தப் பணப்பரிமாற்றமும் நிகழாது.
  • எதிர்பார்க்கப்படும் நெடுவரிசைகள்: payment_id, payment_amount, currency, பணம் செலுத்துபவர் மற்றும் பெறுபவர் பெயர் / IBAN / BIC, requested_execution_date — காற்புள்ளி, அரைப்புள்ளி மற்றும் தத்தல் பிரிப்பான்கள் தானாகக் கண்டறியப்படும். உங்கள் சொந்த ஏற்றுமதிக்கு வார்ப்புருவாகப் பயன்படுத்தக் கீழே ஒரு மாதிரியைப் பதிவிறக்கவும்.
  • கட்டணம் இல்லை. இந்தக் கருவியும், இதன் பின்னணியிலுள்ள முழு கருவித்தொகுப்பும் இலவசம் மற்றும் திறந்த மூலமாகும்.

நீங்களே சரிபார்க்கவும்

"எதுவும் பதிவேற்றப்படுவதில்லை" என்பது இரண்டு நிமிடங்களில் நீங்களே சோதித்துப் பார்க்கக்கூடிய கூற்று:

  1. DevTools → Network-ஐத் திறந்து, பின்னர் செயல்விளக்கத்தைப் பயன்படுத்தவும். இந்தப் பக்கத்தின் சொத்துகள், WASM இயந்திரம் மற்றும் திட்ட வரைவுக்கான same-origin GET கோரிக்கைகள் மட்டுமே இருக்கும் — எதுவும் உங்கள் தரவைக் கொண்டு செல்லாது.
  2. XSD சரிபார்ப்பை ஒருமுறை இயக்கிய பின், DevTools-ஐ Offline நிலைக்கு மாற்றவும் (அல்லது Wi-Fi-ஐ அணைக்கவும்). அதிகாரப்பூர்வ திட்ட வரைவு சரிபார்ப்பு உட்பட முழு செயல்விளக்கமும் தொடர்ந்து செயல்படும்: முதல் பயன்பாட்டிற்குப் பிறகு ஒரு service worker அனைத்தையும் தற்காலிகச் சேமிப்பில் வைத்திருக்கிறது.
  3. இந்தப் பக்கமும் திறந்த மூலமே — செயல்விளக்கத்தின் தர்க்கம் சார்புகள் இல்லாத ஒரே ஒரு தொகுதி; அதை நீங்கள் முழுமையாகப் படிக்கலாம்.

பகுப்பாய்வு ஸ்கிரிப்ட் இல்லை, பிழை-அறிக்கையிடல் சேவை இல்லை, மூன்றாம் தரப்பு எழுத்துரு இல்லை, CSP அறிக்கை முனையமும் இல்லை — அறிக்கையிடலே ஒரு வெளிச்செல்லும் இணைப்பாக இருந்திருக்கும்.

1

உங்கள் பணம் செலுத்தும் தரவைச் சேர்க்கவும்

ஒரு CSV கோப்பை இங்கே இழுத்து விடவும் — அல்லது உலாவக் கிளிக் செய்யவும்

அதிகபட்சம் 2 MB · உங்கள் உலாவியால் உள்ளூரிலேயே படிக்கப்படும்; ஒருபோதும் பதிவேற்றப்படாது

உங்கள் சொந்த வார்ப்புருவாகப் பயன்படுத்த ஒரு மாதிரியைப் பதிவிறக்கவும்: SEPA கடன் பரிமாற்றம் · எல்லை கடந்த பரிமாற்றம் · 20-வரிசைத் தொகுப்பு

3

அதிகாரப்பூர்வ ISO 20022 XSD-க்கு எதிராக நிரூபிக்கவும்

படிகள் 1–2 விரைவான, கையால் எழுதப்பட்ட சோதனைகளை இயக்குகின்றன. இந்தப் படி உண்மையானதையே இயக்குகிறது: ஒரு Python இயக்குநேரம் (WebAssembly வழியாக) xmlschema அதிகாரப்பூர்வ pain.001.001.09 திட்ட வரைவுக்கு எதிராக இயக்குகிறது — CLI செய்யும் அதே வகைச் சரிபார்ப்பு. ~13 MB இயந்திரம் இந்தத் தளத்திலிருந்தே வழங்கப்பட்டு, நீங்கள் கேட்கும்போது ஒருமுறை மட்டும் பதிவிறக்கப்படும் (படி 2 சரியான XML-ஐ உருவாக்கியவுடன் அது அமைதியாகப் பதிவிறக்கத் தொடங்கும்).

முதலில் படி 2-இல் XML-ஐ உருவாக்கவும் — XSD சரிபார்ப்பு அந்த வெளியீட்டையே சரிபார்க்கிறது.

    இந்தப் பக்கத்தில் உள்ள அனைத்தும் உங்கள் உலாவியிலேயே இயங்குகின்றன — எதுவும் பதிவேற்றப்படவோ, சேமிக்கப்படவோ, எங்கும் அனுப்பப்படவோ இல்லை. இந்தச் செயல்விளக்கம் பைப்லைனின் ஒரு உட்பகுதியைச் செயல்படுத்துகிறது (தேவையான புலங்கள், IBAN mod-97, BIC அமைப்பு, தொகை மற்றும் தேதி வடிவங்கள், மீண்டும் கணக்கிடப்படும் NbOfTxs/CtrlSum கட்டுப்பாட்டு மொத்தங்கள்). படி 3 அதிகாரப்பூர்வ XSD சரிபார்ப்பை WebAssembly வழியாக இங்கேயே இயக்குகிறது. நிறுவப்பட்ட கருவித்தொகுப்பு இதன் மேல் JSON Schema சரிபார்ப்பையும் ஐந்து திட்ட விதிநூல்களையும் சேர்க்கிறது — முழுமையான பைப்லைனுக்கு CLI-ஐ நிறுவவும்.

    இந்தச் செயல்விளக்கம் காட்டுவது — மற்றும் உண்மையான பைப்லைன் கூடுதலாக வழங்குவது

    ஒவ்வொரு மாதிரித் தொகுப்பும் உங்கள் சொந்த ERP அல்லது விரிதாள் ஏற்றுமதிக்கு வார்ப்புருவாகப் பயன்படுத்த CSV கோப்பாகவும் பதிவிறக்கக்கூடியது — தலைப்பு வரிசையே ஒப்பந்தம்.

    மேலே உள்ள செயல்விளக்கம் Pain001 பைப்லைனின் fail-fast அடுக்கைச் செயல்படுத்துகிறது: தேவையான-புலச் சோதனைகள், ISO 13616 mod-97 IBAN சரிகாண் தொகைகள், ISO 9362 BIC அமைப்பு, தொகை மற்றும் தேதி வடிவங்கள், மேலும் நம்பிக்கையில் ஏற்காமல் பதிவுகளிலிருந்து மீண்டும் கணக்கிடப்படும் கட்டுப்பாட்டு மொத்தங்கள் (NbOfTxs, CtrlSum). "பிழையை அறிமுகப்படுத்தவும்…" மெனுவை முயற்சிக்கவும் — ஒவ்வொரு சூழ்நிலையும் சரியாக ஒரு யதார்த்தமான குறைபாட்டை (மாற்றப்பட்ட IBAN இலக்கம், தவறான அமைப்பிலான BIC, விடுபட்ட நெடுவரிசை, ஐரோப்பியக் காற்புள்ளி-தசமத் தொகை, சாத்தியமற்ற தேதி) உள்ளிட்டு, வங்கியின் நுழைவாயில் இல்லையெனில் நாட்கள் கழித்து அறிவிக்கக்கூடிய வரிசை-அளவிலான கண்டுபிடிப்பை உங்களுக்குக் காட்டுகிறது.

    நிறுவப்பட்ட கருவித்தொகுப்பு இன்னும் ஆழமான சரிபார்ப்பை இயக்குகிறது: புல-மாற்றுப்பெயர் இயல்பாக்கத்துடன் ஒவ்வொரு பதிவுக்கும் JSON Schema சரிபார்ப்பு, விதிவாரியான --explain வெளியீட்டுடன் ஐந்து திட்ட விதிநூல்கள் (SEPA SCT, Instant, SDD Core, B2B, எல்லை கடந்தவை), மேலும் ஒரு பைட் கூட எழுதப்படுவதற்கு முன் உருவாக்கப்பட்ட ஆவணத்தின் இறுதிச் சரிபார்ப்பு அதிகாரப்பூர்வ ISO 20022 XSD-க்கு எதிராக நடைபெறுகிறது. பத்து pain.001 பதிப்புகளும் pain.008.001.02 ஆதரிக்கப்படுகின்றன.

    pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --scheme sepa-sct --dry-run

    மேலே உள்ள படி 3 ஒரு போலச்செயல் அல்ல: அது WebAssembly-இல் ஒரு Python இயக்குநேரத்தைத் தொடங்கி, இந்தத் தளத்திலிருந்தே வழங்கப்படும் அதிகாரப்பூர்வ pain.001.001.09 திட்ட வரைவுக்கு எதிராக xmlschema-ஐ இயக்குகிறது — CLI பயன்படுத்தும் அதே வகை XSD சரிபார்ப்பு. மீதமுள்ள பைப்லைன் மட்டுமே CLI-க்கு உரியது: JSON Schema இயல்பாக்கம், --explain உடன் கூடிய ஐந்து திட்ட விதிநூல்கள், மற்றும் பிற பத்து செய்தி வரையறைகள்.
