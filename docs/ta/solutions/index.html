Pain001 யாருக்கானது

நான்கு பணிகள், நான்கு சொற்களஞ்சியங்கள், ஒரே pipeline — முதலில் உங்கள் பிரச்சனையைக் கண்டறியுங்கள், பிறகு உங்கள் அடுத்த கிளிக்கை.

2 நிமிட வாசிப்பு கடைசி மதிப்பாய்வு 2026-07-26

கருவூலம் மற்றும் நிதி#

உங்கள் ERP ஒருபோதும் எச்சரிக்காத காரணங்களுக்காக உங்கள் வங்கி கோப்புகளை நிராகரிக்கிறது: இடம் மாறிய IBAN இலக்கம், இனி பொருந்தாத கட்டுப்பாட்டு மொத்தம், ஏற்கத்தக்கதாக இல்லாமல் போன முகவரி வடிவம். Pain001 அந்தத் தோல்விகளை உங்கள் மேசையிலேயே நிகழச் செய்கிறது — ஒவ்வொரு கோப்பும் சமர்ப்பிப்பதற்கு முன் வங்கியின் அதிகாரப்பூர்வ விதிமுறை நூலுக்கு (ISO 20022 XSD) எதிராக நிரூபிக்கப்படுகிறது; ஒவ்வொரு சரிபார்ப்பும் தொடக்கத்திற்கும் சமன்பாட்டுக்கும் இடையில் எங்கு அமர்கிறது என்பதை கட்டண வாழ்க்கைச்சுழற்சி வழிகாட்டி காட்டுகிறது. சொற்கள் புதியதாக இருந்தால் சொற்களஞ்சியத்துடன் தொடங்குங்கள்; எளிய விளக்கங்கள் பொறியாளர்களுக்காக அல்ல, மேசையின் உங்கள் பக்கத்திற்காக எழுதப்பட்டவை.

CFO மற்றும் இயக்குநர் குழு#

இரண்டு எண்கள் இந்த முடிவை வரையறுக்கின்றன. 14 நவம்பர் 2026: கட்டமைக்கப்படாத முகவரிகளுடன் எல்லை கடந்த கட்டணங்கள் நெட்வொர்க் மட்டத்தில் திருப்பப்படத் தொடங்கும் தேதி — இந்த அபாயம் உங்கள் வங்கி இணைப்பில் அல்ல, உங்கள் வாடிக்கையாளர் முதன்மைத் தரவில் உள்ளது. ஆண்டுக்கு €10,000–30,000: அருகிலுள்ள வணிக மொழிமாற்ற SDK-இன் பொது விலை; அதற்கு எதிராக, திறந்த உரிமங்களின் கீழ் எந்த அளவிலும் Pain001-இன் நிரந்தரப் பூஜ்ஜியம். ஆளுகைக் கேள்விகளுக்கு — தணிக்கைத்தன்மை, தரவு இருப்பிடம், விநியோகச் சங்கிலிச் சான்று — உறுதிமொழிகளால் அல்ல, ஆவணங்களால் பதில் அளிக்கப்படுகிறது: வெளியிடப்பட்ட SBOM, பாதுகாப்புக் கொள்கை, உங்கள் உள்கட்டமைப்பை விட்டு ஒருபோதும் வெளியேறாத செயலாக்கம். ஒரு பக்க நிர்வாகச் சுருக்கம் அனுப்பி வைக்கவே எழுதப்பட்டது.

கட்டணச் செயல்பாடுகள்#

நீங்கள் பதில் கோப்புகளிலேயே வாழ்கிறீர்கள். Pain001 சுழற்சியை முழுமையாக மூடுகிறது: CI-இல் தெளிவாகத் தேர்ச்சி அல்லது தோல்வி அடையும் --dry-run முன்-சமர்ப்பிப்புச் சரிபார்ப்புகள், விதிக்கு விதி விளக்கப்பட்ட திட்ட விதிமுறை நூல்கள் (SEPA மற்றும் எல்லை கடந்தவை), திரும்பி வந்ததைப் புரிந்துகொள்ள pain.002 காரணக்-குறியீடு வழிகாட்டி, மேலும் வங்கிப் பதில்களையும் camt.053 அறிக்கைகளையும் உங்கள் pipeline வழிநடத்தக்கூடிய கட்டமைந்த தரவாக மாற்றும் parsers. அது நீக்கும் தோல்வி வகைகளை — ஒரே கிளிக்கில் "பிழையை அறிமுகப்படுத்து" காட்சிகள் உட்பட — காண்பதற்கு உலாவி டெமோ மிக விரைவான வழி.

பொறியியல் மற்றும் AI#

Typed Python API, அர்த்தமுள்ள exit codes கொண்ட CLI, ஒரு REST microservice, மேலும் loaders, validators, schemes, writers ஆகியவற்றுக்கான plugin புள்ளிகள் — தொழில்நுட்ப ஆவணம் ஒவ்வொரு flag மற்றும் endpoint-ஐயும் உள்ளடக்குகிறது; குறியீடு 100% line-and-branch coverage-ஐ கடுமையான CI வாயிலாகக் கொண்டுள்ளது. Agents உடன் உருவாக்குகிறீர்கள் என்றால்: pain001-mcp இந்த வகையின் ஒரே Model Context Protocol சேவையகம் — உங்கள் agents உள்ளூரில் அழைக்கும் பதினேழு read-only கருவிகள், மனிதர்கள் மேற்பார்வையில் இருக்கும்போது pain001-lsp வழங்கும் editor diagnostics உடன்.

Pain001

திறந்த மூல ISO 20022 கட்டணத் தொடக்கம். சரிபார்க்கப்பட்ட கோப்புகள், உள்ளூர் செயலாக்கம், எந்தக் கட்டுப்பாடும் இல்லை.
