சொற்களஞ்சியம்

எளிய மொழியில் ISO 20022 பணப்பரிவர்த்தனை சொற்களஞ்சியம்

எளிய மொழியில் பணப்பரிவர்த்தனைச் சொற்கள் — கோப்புகளை உருவாக்குபவர்களுக்கு மட்டுமல்ல, அவற்றை ஒப்புதல் அளிப்பவர்களுக்கும்.

3 நிமிட வாசிப்பு கடைசி மதிப்பாய்வு 2026-07-26

பொருளடக்கம்

  1. செய்திகள்
  2. திட்டங்களும் விதிநூல்களும்
  3. அடையாளங்காட்டிகளும் தரவும்
  4. இத்தளத்தில் பயன்படும் கருவிச் சொற்கள்

இத்தளத்திலும் உங்கள் வங்கியின் சேனல் ஆவணங்களிலும் வரும் சொற்களுக்கான எளிய மொழி விளக்கங்கள். முதலில் கருவூல அதிகாரிகள் மற்றும் செயல்பாட்டுக் குழுக்களுக்காக, அடுத்து பொறியாளர்களுக்காக எழுதப்பட்டவை.

செய்திகள்#

pain.001 — Customer Credit Transfer Initiation. ஒன்று அல்லது பல வரவு பரிமாற்றங்களைக் கோரி ஒரு வாடிக்கையாளர் தனது வங்கிக்கு அனுப்பும் XML செய்தி. "pain" குடும்பம் என்பது payment initiation; .001 என்பது செய்தி எண்; இறுதியில் வரும் பதிப்பு (.001.09) ஸ்கீமாவை நிர்ணயிக்கிறது.

pain.002 — Customer Payment Status Report. உங்கள் pain.001 அல்லது pain.008-க்கு வங்கியின் பதில்: ஏற்கப்பட்டது, பகுதியாக ஏற்கப்பட்டது, அல்லது நிராகரிக்கப்பட்டது — ஒவ்வொரு பரிவர்த்தனைக்கும் ISO காரணக் குறியீடுகளுடன்.

pain.008 — Customer Direct Debit Initiation. pain.001-ன் வசூல் பக்க இரட்டை: பணத்தை வெளியே அனுப்புவதற்குப் பதிலாக, ஓர் ஆணையின் கீழ் உங்களுக்குச் சேர வேண்டிய நிதியை நீங்கள் பெறுகிறீர்கள்.

pacs.008 / pacs.009. வங்கி உங்கள் அறிவுறுத்தலை ஏற்றவுடன் அது மாறும் வங்கிகளுக்கிடையிலான தீர்வுச் செய்திகள். நிறுவனங்கள் இவற்றை ஒருபோதும் உருவாக்குவதில்லை; வங்கிகளே இவற்றைப் பரிமாறிக் கொள்கின்றன.

camt.052 / camt.053 / camt.054. கணக்கு அறிக்கையிடல்: முறையே நாளுக்குள்ளான அறிக்கை, நாள் இறுதி அறிக்கை, பற்று/வரவு அறிவிப்பு. ஒப்புரவுக் குழுக்கள் ஒவ்வொரு காலையிலும் பயன்படுத்துவது camt.053-ஐத்தான்.

MT101. pain.001 இடம்பிடிக்கும் பழைய SWIFT "Request for Transfer" உரைச் செய்தி. வங்கிகளுக்கிடையிலான MT101 அனுப்புகை 14 நவம்பர் 2026 அன்று நிறுத்தப்பட்டு pain.001.001.09-க்கு வழிவிடுகிறது; நிறுவனத்திலிருந்து வங்கிக்கான MT101 ஒவ்வொரு வங்கியின் விருப்பத்தின் பேரில் மட்டுமே நீடிக்கிறது.

திட்டங்களும் விதிநூல்களும்#

SEPA SCT / SCT Inst. European Payments Council விதிநூல்களால் நிர்வகிக்கப்படும் யூரோ வரவு-பரிமாற்றத் திட்டங்கள் (நிலையானது மற்றும் உடனடியானது). உடனடிப் பரிமாற்றங்கள் நாள் முழுவதும், நொடிகளில் தீர்வு காணப்படுகின்றன.

SEPA SDD Core / B2B. யூரோ நேரடிப் பற்றுத் திட்டங்கள் — நுகர்வோருக்கு Core (திரும்பப் பெறும் உரிமையுடன்), வணிகங்களுக்கு B2B (திரும்பப் பெறும் உரிமை இல்லை, கடுமையான ஆணைச் சோதனைகள்).

CBPR+. Cross-Border Payments and Reporting Plus: SWIFT தொடர்பு வங்கிச் சேவைக்காக ISO 20022 செய்திகளை வரையறுக்கும் பயன்பாட்டு வழிகாட்டுதல்கள். மக்கள் "SWIFT ISO 20022 இடம்பெயர்வு" என்று சொல்லும்போது அவர்கள் குறிப்பிடுவது CBPR+ ஐத்தான்.

HVPS+. உயர்-மதிப்புப் பணப்பரிவர்த்தனை அமைப்புகளுக்கான (T2, CHAPS, Fedwire மற்றும் அதுபோன்றவை) இணையான வரையறை.

CGI-MP. Common Global Implementation — Market Practice: பல்வேறு வங்கிகளில் நிறுவனங்கள் pain செய்திகளைப் பயன்படுத்தும் முறையை ஒருங்கிணைக்கும் குழு; இதனால் ஒரே கோப்பு வடிவம் பல வங்கிக் கூட்டாளிகளுக்குப் பயன்படும்.

Verification of Payee (VoP). 9 அக்டோபர் 2025 முதல் அனைத்து SEPA வரவு பரிமாற்றங்களுக்கும் பொருந்தும், EU கட்டாயமாக்கிய பெயர்/IBAN பொருத்தச் சோதனை. செயல்படுத்தும் நேரத்தில் PSP இதைச் செய்கிறது; பொருந்துமா என்பதைத் தீர்மானிப்பது தூய்மையான கடனாளர் தரவே.

அடையாளங்காட்டிகளும் தரவும்#

IBAN. International Bank Account Number (ISO 13616), mod-97 செக்சம் மூலம் தன்னைத்தானே சரிபார்த்துக் கொள்வது — இதனால்தான் ஒரே ஓர் இலக்கு இடம்மாறியிருந்தாலும் அதைச் சமர்ப்பிப்பதற்கு முன்பே கண்டறிய முடிகிறது.

BIC / BICFI. ஒரு நிதி நிறுவனத்தின் ISO 9362 Business Identifier Code. pain.001.001.03-இல் XML கூறு ; ஆனால் பதிப்பு 9 முதல் — பதிப்பு மேம்படுத்தல்களின்போது நிஜமான நிராகரிப்புகளை ஏற்படுத்தும் ஒரு பெயர் மாற்றம்.

LEI. Legal Entity Identifier (ISO 17442) — 20 எழுத்துகள் கொண்ட உலகளாவிய நிறுவன அடையாளங்காட்டி. 3 மில்லியனுக்கும் மேற்பட்டவை செயலில் உள்ளன; ஒழுங்குமுறை அமைப்புகள் பணப்பரிவர்த்தனைகளில் இவற்றை மேலும் மேலும் கட்டாயமாக்கி வருகின்றன.

UETR. Unique End-to-end Transaction Reference — தொடர்பு வங்கிச் சங்கிலி முழுவதும் ஒரு பணப்பரிவர்த்தனையைத் தடமறியச் செய்யும் UUID (SWIFT gpi).

கட்டமைக்கப்பட்ட / கலப்பு முகவரி. சுதந்திரப் பாட வரிகளுக்குப் பதிலாக, தனித்தனி XML கூறுகளாக அமையும் அஞ்சல் முகவரிகள் (தெரு, ஊர், அஞ்சல் குறியீடு, நாடு). 14 நவம்பர் 2026 முதல் CBPR+ முற்றிலும் கட்டமைக்கப்படாத முகவரிகளை நிராகரிக்கிறது; கலப்பு — கட்டமைக்கப்பட்ட ஊர், நாடு உடன் அதிகபட்சம் இரண்டு 70-எழுத்து முகவரி வரிகள் — செல்லுபடியாகவே இருக்கும்.

NbOfTxs / CtrlSum. குழுத் தலைப்பின் கட்டுப்பாட்டு மொத்தங்கள்: பரிவர்த்தனை எண்ணிக்கையும் தொகைக் கூட்டுத்தொகையும். வங்கிகள் இவற்றை மறுகணக்கிடுகின்றன; உங்களுடையவை பொருந்தவில்லை என்றால் கோப்பு திருப்பியனுப்பப்படும். Pain001 எப்போதும் சரிபார்க்கப்பட்ட பதிவுகளிலிருந்தே இவற்றைப் பெறுகிறது.

கட்டணம் ஏற்பவர். கட்டணங்களைச் செலுத்துவது யார்: DEBT (அனுப்புநர்), CRED (பெறுநர்), SHAR (பகிர்ந்து), SLEV (திட்ட விதிகளின்படி). பழைய MT OUR/BEN/SHA ஆகியவை முதல் மூன்றுடன் பொருந்துகின்றன.

பணவனுப்பல் தகவல். "இந்தப் பணப்பரிவர்த்தனை எதற்காக" என்ற புலம் — சுதந்திர உரை (140 எழுத்துகள்) அல்லது கட்டமைக்கப்பட்ட குறிப்புகள். அனைவரும் இதைச் சரியாக நிரப்ப வேண்டும் என ஒப்புரவுக் குழுக்கள் விரும்பும் ஒன்று.

இத்தளத்தில் பயன்படும் கருவிச் சொற்கள்#

XSD சரிபார்ப்பு. அதிகாரப்பூர்வ ISO 20022 ஸ்கீமா வரையறைக்கு எதிராக XML-ஐச் சோதிப்பது. எந்தக் கோப்பும் எழுதப்படுவதற்கு முன் Pain001 இதைக் கடும் நுழைவாயிலாகக் கருதுகிறது.

MCP — Model Context Protocol. AI உதவியாளர்கள் வெளிப்புறக் கருவிகளை அழைக்கப் பயன்படும் திறந்த தரநிலை. pain001-mcp எந்த MCP கிளையண்டுக்கும் உள்ளூரில் stdio வழியாக 17 பணப்பரிவர்த்தனைக் கருவிகளை வழங்குகிறது.

LSP — Language Server Protocol. IDE பிழைக் கண்டறிதலுக்குப் பின்னால் உள்ள எடிட்டர்-ஒருங்கிணைப்புத் தரநிலை. pain001-lsp இதைப் பயன்படுத்தி நீங்கள் தட்டச்சு செய்யும்போதே பணப்பரிவர்த்தனைக் கோப்புகளைச் சரிபார்க்கிறது.

SBOM. Software Bill of Materials — ஒரு வெளியீட்டில் உள்ள ஒவ்வொரு சார்பையும் பட்டியலிடும், இயந்திரம் படிக்கக்கூடிய பட்டியல்; Pain001 மைய வெளியீடுகளுக்கு CycloneDX வடிவில் உருவாக்கப்படுகிறது.

ஏதேனும் விடுபட்டுள்ளதா? ஒரு சொல்லைப் பரிந்துரையுங்கள் — மக்கள் உண்மையில் கேட்கும் கேள்விகளுக்கு ஏற்பவே இந்தச் சொற்களஞ்சியம் வளர்கிறது.
