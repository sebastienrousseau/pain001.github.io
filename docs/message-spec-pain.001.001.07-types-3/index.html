Complex types in ISO 20022 pain.001.001.07, generated from the official XSD. Part 3 of 3 — SupplementaryData1 – TaxRecordDetails1.

Part 1 · Part 2 · Part 3

Each type is defined once here. The message structure repeats a party or address block under every party; this view does not, which is what you want when mapping source fields.

A choice type means the children are alternatives — supply one, not all. Cardinality in bold is required.
