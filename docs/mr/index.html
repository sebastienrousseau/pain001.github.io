मराठीत Pain001

Pain001 — ओपन-सोर्स ISO 20022 पेमेंट आरंभ

तुमचा पेमेंट डेटा पडताळलेल्या ISO 20022 XML मध्ये रूपांतरित करणारे ओपन-सोर्स सूट — बँकेपर्यंत पोहोचण्यापूर्वीच अचूक सिद्ध.

1 min read Last reviewed 26 July 2026

तुमची बँक नाकारणार नाही अशा पेमेंट फाइल्स#

Pain001 हे ISO 20022 पेमेंट आरंभासाठी ओपन-सोर्स Python सूट आहे. तुमच्याकडे आधीच असलेला डेटा — CSV, Excel, SQLite, JSON, Parquet किंवा जुने SWIFT MT101 संदेश — अधिकृत XSD स्कीमांनी पडताळलेल्या pain.001 (क्रेडिट ट्रान्सफर) आणि pain.008 (डायरेक्ट डेबिट) XML मध्ये रूपांतरित करते.

प्रत्येक फाइल लिहिण्यापूर्वी तीन पडताळणी स्तरांतून जाते: प्रत्येक नोंदीसाठी JSON स्कीमा (IBAN ची mod-97 तपासणी आणि BIC रचना यासह), scheme नियम (SEPA आणि सीमापार CBPR+) आणि अंतिम XSD पडताळणी. नियंत्रण बेरजा नेहमी पुन्हा मोजल्या जातात, कधीही कॉपी होत नाहीत. सर्व काही स्थानिक चालते: कोणताही पेमेंट डेटा तुमच्या पायाभूत सुविधेबाहेर जात नाही.

14 नोव्हेंबर 2026 ची अंतिम मुदत#

22 नोव्हेंबर 2025 रोजी MT–MX सहअस्तित्व संपल्यानंतर पुढील मुदत 14 नोव्हेंबर 2026: पूर्णपणे असंरचित पत्ते CBPR+ पेमेंटमध्ये नाकारले जातील आणि आंतर-बँक MT101 रिलेची जागा pain.001 आवृत्ती 9 घेईल. Pain001 आजच संरचित आणि हायब्रिड पत्ते तयार करते — आणि एका कमांडने MT101 रूपांतरित करते.

सुरुवात करा#

pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --dry-run

संपूर्ण दस्तऐवजीकरण इंग्रजीत आहे: इन्स्टॉलेशन मार्गदर्शक, तांत्रिक संदर्भ, ब्राउझर डेमो आणि 2026 ISO 20022 ब्रीफिंग. कोरला Apache-2.0 / MIT दुहेरी परवाना — कोणत्याही प्रमाणात मोफत व्यावसायिक वापर.
