Pain001 इन्स्टॉल करा: pip, Docker व पहिली प्रमाणित फाइल

Python 3.10–3.12, pip किंवा Docker, आणि तीन आदेशांत एक प्रमाणित पेमेंट फाइल.

2 मिनिटे वाचन शेवटची तपासणी 2026-07-26

अनुक्रमणिका

  1. PyPI
  2. Docker
  3. निर्बंधित वातावरणे
  4. तीन आदेशांत पहिली फाइल

Pain001 हे macOS, Linux आणि Windows वर Python 3.10, 3.11 आणि 3.12 वर चालते (प्रत्येक आवृत्ती CI मध्ये तपासली जाते). तुम्हाला आवश्यक तेवढेच इन्स्टॉल करा; प्रत्येक पर्यायी क्षमता एक्स्ट्रा असल्याने मूळ इन्स्टॉलेशन हलके राहते.

01. PyPI#

तुम्हाला काय हवे आदेश
मुख्य CLI व Python लायब्ररी pip install pain001
REST API मायक्रोसर्व्हिस (FastAPI + Uvicorn) pip install "pain001[api]"
Parquet डेटा वाचन (PyArrow) pip install "pain001[parquet]"
PGP-एन्क्रिप्टेड इनपुट फाइल (.gpg / .asc) pip install "pain001[gpg]"
API साठी Redis-आधारित असिंक्रोनस जॉब रांग pip install "pain001[redis]"
OpenTelemetry ट्रेसिंग pip install "pain001[otel]"
अंतर्भूत किमान MCP / LSP सर्व्हर pip install "pain001[mcp]" / "pain001[lsp]"

सहयोगी पॅकेजेस स्वतंत्रपणे इन्स्टॉल होतात आणि त्यांच्या आवृत्त्याही स्वतंत्र असतात:

pip install pain001-loader-xlsx    # Excel ingestion (auto-discovered plugin)
pip install pain001-loader-mt101   # SWIFT MT101 parsing library
pip install pain001-mcp            # Full 17-tool MCP server for AI agents
pip install pain001-lsp            # Full six-feature editor language server

इन्स्टॉलेशन तपासा आणि संदेश सूची पाहा:

pain001 --version
pain001 versions          # list all 11 supported message definitions
pain001 init pain.001.001.09   # scaffold a starter CSV template

02. Docker#

बहु-आर्किटेक्चर प्रतिमा (linux/amd64, linux/arm64) GitHub Container Registry वर प्रकाशित केल्या जातात. कंटेनर स्वतंत्र नॉन-रूट वापरकर्ता म्हणून चालतो.

# Generate XML from a local CSV
docker run --rm -v "$PWD:/data" -w /data \
  ghcr.io/sebastienrousseau/pain001:latest \
  generate -t pain.001.001.09 -d payments.csv -o out/

# Launch the REST API
docker run --rm -p 8000:8000 \
  ghcr.io/sebastienrousseau/pain001:latest \
  serve --host 0.0.0.0 --port 8000

03. निर्बंधित वातावरणे#

बँक व ट्रेझरी वातावरणांत डायनॅमिक प्लगइन लोडिंगला अनेकदा बंदी असते. नेमक्या याच परिस्थितीसाठी दोन नियंत्रणे उपलब्ध आहेत:

  • PAIN001_DISABLE_PLUGINS=1 सर्व तृतीय-पक्ष प्लगइन शोध बंद करते; केवळ अंतर्भूत लोडरच चालतात.
  • pain001 plugins list / pain001 plugins show <name> शोधलेले प्रत्येक प्लगइन पहिल्या वापराआधीच लेखापरीक्षणयोग्य करतात.

सर्व काही स्थानिक पातळीवरच चालते. या संचातील कोणतेही पॅकेज बाहेर संपर्क साधत नाही, SaaS API ला कॉल करत नाही किंवा पेमेंट डेटा होस्टबाहेर नेत नाही.

04. तीन आदेशांत पहिली फाइल#

pip install pain001
pain001 init pain.001.001.09 -o work/
pain001 -t pain.001.001.09 -d work/template.csv -o work/ --dry-run

--dry-run आउटपुट न लिहिता JSON Schema, XSD आणि (--scheme सह) SEPA किंवा सीमापार नियमपुस्तिकेविरुद्ध प्रमाणीकरण करते — एक्झिट कोड 0 म्हणजे फाइल त्या तपासण्यांमध्ये उत्तीर्ण झाली: स्कीमा, आणि निवडलेली असल्यास scheme नियमपुस्तिका. तुमच्या बँकेची स्वतःची प्रोफाइल आणि चॅनेलसंबंधी नियम वेगळे आहेत आणि त्यांसाठी अजूनही बँकेसोबत चाचणी आवश्यक आहे. XML लिहिण्यासाठी --dry-run काढून टाका.

प्रत्येक फ्लॅग व एंडपॉइंटसाठी तांत्रिक संदर्भ पाहा, किंवा प्रत्यक्ष कामकाजाच्या प्रश्नांसाठी क्विकस्टार्ट FAQ पाहा.
