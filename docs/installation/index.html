Pain001 Installation Guide: PyPI, Extras, Docker & Kubernetes

Complete installation options for Pain001 suite including PyPI, optional extras, companion loaders, Docker, and Kubernetes.

<div lang="en"><h1>Pain001 Installation & Deployment Guide</h1> <p>Pain001 requires <strong>Python 3.10 or later</strong> and runs natively on macOS, Linux, and Windows.</p> <hr /> <h2>1.
