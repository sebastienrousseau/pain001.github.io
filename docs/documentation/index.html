Pain001 Documentation & Comprehensive API Reference

Complete API reference for Pain001 CLI, Python library, REST API, scheme validators, streaming mode, and input normalization.

<div lang="en"><h1>Pain001 Suite Documentation & Technical Reference</h1> <p>This reference covers the CLI options, Python public API, REST microservice endpoints, scheme validators, and input normalization rules across the entire Pain001 ecosystem.</p> <hr /> <h2>1. Command-Line Interface (CLI)</h2> <p>The <code>pain001</code> binary resolves templates and XSD schemas automatically from its bundled registry.</p> <h3>Required Arguments</h3> <ul> <li><code>-t, --xmltype <TYPE></code>: Message type (e.g. <code>pain.001.001.03</code>, <code>pain.001.001.09</code>, <code>pain.001.001.11</code>, <code>pain.008.001.02</code>).</li> <li><code>-d, --data <FILE></code>: Path to input data file (<code>.csv</code>, <code>.xlsx</code>, <code>.sqlite</code>, <code>.json</code>, <code>.jsonl</code>, <code>.parquet</code>).</li> </ul> <h3>Optional Arguments & Flags</h3> <ul> <li><code>-o, --output <FILE></code>: Output XML file path (defaults to <code><xmltype>.xml</code>).</li> <li><code>-m, --template <FILE></code>: Custom XML template path.</li> <li><code>-s, --schema <FILE></code>: Custom XSD schema path.</li> <li><code>--scheme <SCHEME></code>: Enforce scheme rulebook checks (<code>sepa-sct</code>, <code>sepa-sdd</code>, <code>sepa-inst</code>, <code>sepa-b2b</code>, <code>xborder-ct</code>).</li> <li><code>--dry-run</code>: Validate input data against XSD and scheme rules without writing output file (Exit code <code>0</code> for valid, <code>1</code> for invalid).</li> <li><code>--streaming</code>: Enable memory-bounded chunked input processing for large datasets.</li> <li><code>--chunk-size <N></code>: Number of transactions per output chunk (default: <code>1000</code>).</li> </ul> <hr /> <h2>2. REST Microservice API</h2> <p>Launch the bundled FastAPI + Uvicorn server:</p> <pre><code class="language-bash"><pre style="background-color:#2b303b;"> <span style="color:#8fa1b3;">pip</span><span style="color:#c0c5ce;"> install "</span><span style="color:#a3be8c;">pain001[api]</span><span style="color:#c0c5ce;">" </span><span style="color:#8fa1b3;">pain001</span><span style="color:#c0c5ce;"> serve</span><span style="color:#bf616a;"> --host</span><span style="color:#c0c5ce;"> 0.0.0.0</span><span style="color:#bf616a;"> --port</span><span style="color:#c0c5ce;"> 8000 </span></pre> </code></pre> <h3>Endpoints</h3> <ul> <li><code>POST /v1/generate</code>: Ingests JSON payload or file upload and returns generated ISO 20022 XML.</li> <li><code>POST /v1/validate</code>: Ingests JSON payload and returns validation status with precise field-level errors.</li> <li><code>GET /health</code>: Health check and system status.</li> </ul> <hr /> <h2>4. Input Normalization & Field Aliases</h2> <p>Pain001 automatically coerces user inputs to validate on the first try:</p> <ul> <li>Field name alias matching (<code>amount</code> -> <code>payment_amount</code>, <code>execution_date</code> -> <code>requested_execution_date</code>).</li> <li>IBAN / BIC lowercase normalization and whitespace stripping.</li> <li>Date string parsing (ISO 8601 <code>YYYY-MM-DD</code>).</li> <li>Precision protection: Numerical amounts are coerced through <code>decimal.Decimal</code> to prevent floating-point inaccuracies.</li> </ul> </div>
