# Migration to v0.0.3

This release changes the website theme and repository process; it does not
change the Pain001 XML API or message semantics.

- The site now requires Shokunin SSG 0.0.63.
- Front-matter social handles are quoted for strict YAML parsing.
- PRISM and Skeletonic CSS v3.0.0 are vendored under `static/`.
- Colour mode cycles system → light → dark → system. System follows the OS
  preference and changes live when the OS changes.
- Pages can be saved locally in the browser; no bookmark data leaves the
  device.
- Release tags are sequential, signed, and accompanied by GitHub releases.

Clear an old explicit colour choice by cycling the control back to System, or
remove the `theme` key from local storage.
