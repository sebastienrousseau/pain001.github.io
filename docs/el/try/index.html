Διαδραστική επίδειξη

Δοκιμάστε το Pain001 στον περιηγητή σας

Σύρετε ένα αρχείο CSV, χρησιμοποιήστε το δείγμα ή επικολλήστε τις δικές σας εγγραφές — η επικύρωση εκτελείται αμέσως, εξ ολοκλήρου στον περιηγητή σας, και τίποτα δεν φεύγει ποτέ από τον υπολογιστή σας.

Πώς σας βοηθά αυτό το εργαλείο επικύρωσης

  • ✓Δοκιμάστε τα δεδομένα πληρωμών σας με τους ελέγχους που εφαρμόζουν οι τράπεζες — υποχρεωτικά πεδία, ψηφία ελέγχου IBAN, δομή BIC, σύνολα ελέγχου
  • ✓Δημιουργήστε ένα λειτουργικό αρχείο μεταφοράς πίστωσης pain.001.001.09 που μπορείτε να εξετάσετε, να αντιγράψετε ή να λάβετε
  • ✓Επαληθεύστε το αποτέλεσμα έναντι του επίσημου σχήματος ISO 20022 — το γνήσιο XSD, επικυρωμένο στον περιηγητή σας

Σημαντικές πληροφορίες

  • Τίποτα δεν μεταφορτώνεται. Το αρχείο σας διαβάζεται από τον δικό σας περιηγητή και δεν φεύγει ποτέ από τον υπολογιστή σας — δεν υπάρχει διακομιστής, αποθήκευση ή τηλεμετρία. Ασφαλές και για πραγματικά δεδομένα, αν και η χρήση συγκαλυμμένων δοκιμαστικών δεδομένων αποτελεί πάντοτε ορθή πρακτική.
  • Αποκλειστικά εργαλείο δοκιμών. Τα αρχεία δεν υποβάλλονται ποτέ προς επεξεργασία και καμία πληρωμή δεν μπορεί να προκύψει από οτιδήποτε κάνετε εδώ.
  • Αναμενόμενες στήλες: payment_id, payment_amount, currency, όνομα / IBAN / BIC οφειλέτη και δικαιούχου, requested_execution_date — τα διαχωριστικά κόμματος, ερωτηματικού (;) και στηλοθέτη εντοπίζονται αυτόματα. Κατεβάστε ένα δείγμα παρακάτω για να το χρησιμοποιήσετε ως πρότυπο για τη δική σας εξαγωγή.
  • Χωρίς χρεώσεις. Αυτό το εργαλείο, όπως και η πλήρης εργαλειοθήκη πίσω από αυτό, διατίθενται δωρεάν και ως λογισμικό ανοικτού κώδικα.

Επαληθεύστε το μόνοι σας

Το «Τίποτα δεν μεταφορτώνεται» είναι ένας ισχυρισμός που μπορείτε να ελέγξετε μόνοι σας μέσα σε δύο λεπτά:

  1. Ανοίξτε τα DevTools → Network και, στη συνέχεια, χρησιμοποιήστε την επίδειξη. Τα μόνα αιτήματα είναι GET ίδιας προέλευσης για τα στοιχεία αυτής της σελίδας, τη μηχανή WASM και το σχήμα — κανένα δεν μεταφέρει τα δεδομένα σας.
  2. Εκτελέστε μία φορά τον έλεγχο XSD και έπειτα θέστε τα DevTools σε λειτουργία Offline (ή απενεργοποιήστε το Wi-Fi). Ολόκληρη η επίδειξη — συμπεριλαμβανομένου του ελέγχου με το επίσημο σχήμα — εξακολουθεί να λειτουργεί: ένα service worker αποθηκεύει τα πάντα στην κρυφή μνήμη μετά την πρώτη χρήση.
  3. Και αυτή η σελίδα είναι ανοικτού κώδικα — η λογική της επίδειξης είναι ένα ενιαίο module χωρίς εξαρτήσεις, το οποίο μπορείτε να διαβάσετε ολόκληρο.

Δεν υπάρχει σενάριο αναλυτικών στοιχείων, υπηρεσία αναφοράς σφαλμάτων, γραμματοσειρά τρίτων ή τελικό σημείο αναφορών CSP — η ίδια η αναφορά θα αποτελούσε εξερχόμενη σύνδεση.

3

Επαληθεύστε το έναντι του επίσημου XSD του ISO 20022

Τα βήματα 1–2 εκτελούν γρήγορους, χειρόγραφους ελέγχους. Αυτό το βήμα εκτελεί το αυθεντικό: ένα περιβάλλον εκτέλεσης Python (μέσω WebAssembly) που τρέχει το xmlschema έναντι του επίσημου σχήματος pain.001.001.09 — η ίδια κατηγορία επικύρωσης που εκτελεί και το CLI. Η μηχανή των ~13 MB εξυπηρετείται από αυτόν τον ιστότοπο και λαμβάνεται μία μόνο φορά, όταν τη ζητήσετε (η λήψη ξεκινά διακριτικά μόλις το βήμα 2 παραγάγει έγκυρο XML).

Δημιουργήστε πρώτα XML στο βήμα 2 — ο έλεγχος XSD επικυρώνει αυτό το αποτέλεσμα.

    Όλα σε αυτή τη σελίδα εκτελούνται στον περιηγητή σας — τίποτα δεν μεταφορτώνεται, δεν αποθηκεύεται ούτε αποστέλλεται πουθενά. Αυτή η επίδειξη υλοποιεί ένα υποσύνολο της ροής επεξεργασίας (υποχρεωτικά πεδία, IBAN mod-97, δομή BIC, μορφές ποσών και ημερομηνιών, επανυπολογισμένα NbOfTxs/CtrlSum σύνολα ελέγχου). Το βήμα 3 εκτελεί τον επίσημο έλεγχο XSD εδώ ακριβώς, μέσω WebAssembly. Η εγκατεστημένη εργαλειοθήκη προσθέτει επιπλέον επικύρωση JSON Schema και πέντε σύνολα κανόνων συστημάτων πληρωμών — εγκαταστήστε το CLI για την πλήρη ροή επεξεργασίας.

    Τι δείχνει αυτή η επίδειξη — και τι προσθέτει η πραγματική ροή επεξεργασίας

    Κάθε δείγμα παρτίδας είναι επίσης διαθέσιμο για λήψη ως αρχείο CSV, ώστε να το χρησιμοποιήσετε ως πρότυπο για τη δική σας εξαγωγή από ERP ή υπολογιστικό φύλλο — η γραμμή κεφαλίδων αποτελεί τη σύμβαση.

    Η παραπάνω επίδειξη υλοποιεί το επίπεδο ταχείας απόρριψης σφαλμάτων της ροής επεξεργασίας του Pain001: ελέγχους υποχρεωτικών πεδίων, ψηφία ελέγχου IBAN mod-97 κατά ISO 13616, δομή BIC κατά ISO 9362, μορφές ποσών και ημερομηνιών, καθώς και σύνολα ελέγχου (NbOfTxs, CtrlSum) που επανυπολογίζονται από τις εγγραφές αντί να θεωρούνται δεδομένα. Δοκιμάστε το μενού «Εισαγωγή σφάλματος…» — κάθε σενάριο εισάγει ακριβώς ένα ρεαλιστικό ελάττωμα (ένα αντεστραμμένο ψηφίο IBAN, ένα εσφαλμένα δομημένο BIC, μια στήλη που λείπει, ένα ποσό με ευρωπαϊκή υποδιαστολή, μια ανύπαρκτη ημερομηνία) και σας δείχνει το εύρημα σε επίπεδο γραμμής που η πύλη μιας τράπεζας θα σας ανέφερε, διαφορετικά, ημέρες αργότερα.

    Η εγκατεστημένη εργαλειοθήκη εκτελεί έναν πολύ βαθύτερο έλεγχο: επικύρωση JSON Schema ανά εγγραφή με κανονικοποίηση ψευδωνύμων πεδίων, πέντε σύνολα κανόνων συστημάτων πληρωμών (SEPA SCT, Instant, SDD Core, B2B, διασυνοριακές πληρωμές) με αποτελέσματα --explain κανόνα προς κανόνα, και τελική επικύρωση του παραγόμενου εγγράφου έναντι του επίσημου XSD του ISO 20022 πριν γραφτεί έστω και ένα byte. Δέκα εκδόσεις pain.001 και το pain.008.001.02 υποστηρίζονται.

    pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --scheme sepa-sct --dry-run

    Το βήμα 3 παραπάνω δεν είναι προσομοίωση: εκκινεί ένα περιβάλλον εκτέλεσης Python σε WebAssembly και τρέχει το xmlschema έναντι του επίσημου σχήματος pain.001.001.09 που εξυπηρετείται από αυτόν τον ιστότοπο — η ίδια κατηγορία ελέγχου XSD που εφαρμόζει και το CLI. Ό,τι παραμένει διαθέσιμο μόνο μέσω CLI είναι το υπόλοιπο της ροής επεξεργασίας: η κανονικοποίηση JSON Schema, τα πέντε σύνολα κανόνων συστημάτων πληρωμών με --explain, και οι υπόλοιποι δέκα ορισμοί μηνυμάτων.
