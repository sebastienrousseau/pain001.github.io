## 은행보다 먼저 지급 파일 오류를 찾아내세요

**Pain001**은 ISO 20022 지급 지시를 위한 오픈소스 Python 스위트입니다. 이미 보유한 데이터 — CSV, Excel, SQLite, JSON, Parquet 또는 기존 SWIFT MT101 메시지 — 를 공식 XSD 스키마로 검증된 `pain.001`(계좌이체) 및 `pain.008`(자동이체) XML로 변환합니다.

모든 파일은 기록되기 전에 세 단계 검증을 거칩니다. 레코드별 JSON 스키마(IBAN mod-97 검사와 BIC 구조 포함), 스킴 규칙(SEPA 및 국경 간 CBPR+), 최종 XSD 검증입니다. 컨트롤 합계는 항상 재계산되며 복사되지 않습니다. 모든 것이 로컬에서 실행되어 결제 데이터가 인프라 밖으로 나가지 않습니다.

## 브라우저에서 사용해 보기

샘플 배치를 브라우저에서 바로 검증하세요 — 아무것도 업로드되지 않습니다 — 결과는 공식 XSD 스키마로 증명됩니다: [Pain001 사용해 보기](/try/). 샘플 CSV 파일은 자체 내보내기용 템플릿으로 다운로드할 수 있습니다.

## 2026년 11월 14일 기한

2025년 11월 22일 MT–MX 공존 기간이 끝난 뒤 다음 기한은 **2026년 11월 14일**입니다. 완전히 비구조화된 주소는 CBPR+ 결제에서 거부되며, 은행 간 MT101 릴레이는 `pain.001` 버전 9로 대체됩니다. Pain001은 오늘부터 구조화 및 하이브리드 주소를 생성하고, MT101을 명령 하나로 변환합니다.

## 시작하기

```bash
pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --dry-run
```
