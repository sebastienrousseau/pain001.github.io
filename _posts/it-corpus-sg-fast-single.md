Descrizione dello scenario, citata dal record di provenienza (testo originale in inglese):

> Singapore FAST credit in SGD, bank and branch codes, addresses on both parties.

Un file di disposizione di pagamento (**SG**, circuito **instant-payment**), fornito in `pain.001.001.03`, `pain.001.001.09`, generato e verificato da pain001 0.0.70. È un esempio sintetico costruito dai regolamenti pubblici degli schemi di pagamento: nessuna parte reale, nessun conto reale, nessuna linea guida bancaria dietro di esso.

Il gemello è lo stesso pagamento nella convenzione JSON della Registration Authority ISO 20022, senza perdite in entrambe le direzioni; il suo JSON Schema (2020-12) è pubblicato per edizione: [pain.001.001.03](/corpus/schemas/pain.001.001.03.schema.json), [pain.001.001.09](/corpus/schemas/pain.001.001.09.schema.json). Un agente può produrre un gemello valido rispetto allo schema e consegnarlo alla libreria per generare l'XML.

[Apri questo scenario nella demo](/it/try/?sample=corpus:sg.fast.single): la libreria pain001 si carica in un runtime Python nel tuo browser, ricostruisce il file dai 1 record qui sotto, lo verifica rispetto al regolamento `sg-fast` e all'XSD ufficiale e mostra il gemello JSON.
