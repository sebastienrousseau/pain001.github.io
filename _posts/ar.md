## ملفات دفع لن يرفضها بنكك

**Pain001** حزمة Python مفتوحة المصدر لبدء المدفوعات وفق ISO 20022. تحوِّل البيانات الموجودة لديك — CSV أو Excel أو SQLite أو JSON أو Parquet أو رسائل SWIFT MT101 القديمة — إلى XML من نوع `pain.001` (التحويلات) و `pain.008` (الخصم المباشر)، موثَّقة بمخططات XSD الرسمية.

يمر كل ملف بثلاث طبقات تحقق قبل كتابته: مخطط JSON لكل سجل (مع فحص mod-97 لرقم IBAN وبنية BIC)، وقواعد النظام (SEPA و CBPR+ العابر للحدود)، ثم التحقق النهائي بمخطط XSD. تُعاد حساب المجاميع الرقابية ولا تُنسخ أبداً. كل شيء يعمل محلياً: لا تغادر أي بيانات دفع بنيتك التحتية.

## جرّبه في المتصفح

تحقّق من دفعة نموذجية مباشرة في متصفحك — لا يُرفع أي شيء — وأثبت النتيجة بمخطط XSD الرسمي: [جرّب Pain001](/try/). ملفات CSV نموذجية متاحة للتنزيل كقوالب لتصديراتك الخاصة.

## الموعد النهائي: 14 نوفمبر 2026

بعد انتهاء التعايش بين MT وMX في 22 نوفمبر 2025، الموعد التالي هو **14 نوفمبر 2026**: سترفض المدفوعات عبر CBPR+ العناوين البريدية غير المهيكلة بالكامل، وسيحل `pain.001` الإصدار 9 محل ترحيل MT101 بين البنوك. يدعم Pain001 اليوم العناوين المهيكلة والهجينة — ويحوِّل MT101 بأمر واحد.

## ابدأ الآن

```bash
pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --dry-run
```
