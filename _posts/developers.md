## Ways to run it

| Interface | Use it for | Start here |
| :--- | :--- | :--- |
| Python library | Generating and validating files inside your own code | [Technical reference](/documentation/) |
| Command line | Batch jobs and scripts | [Installation](/installation/) |
| REST API | A service other systems call, inside your network | [Technical reference](/documentation/) |
| MCP server | Read-only payment tools for AI agents | [pain001-mcp](/pain001-mcp/) |
| Language server | Diagnostics in your editor while you write the data | [pain001-lsp](/pain001-lsp/) |
| Loaders | MT101 requests and Excel workbooks as input | [MT101 loader](/pain001-loader-mt101/), [Excel loader](/pain001-loader-xlsx/) |

## Check files in CI

The core repository is also a GitHub Action: [check payment files on every pull request](/developers/ci/).
