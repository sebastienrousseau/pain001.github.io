## ตรวจพบข้อผิดพลาดในไฟล์การชำระเงินก่อนที่ธนาคารของคุณจะตรวจพบ

**Pain001** คือชุดเครื่องมือ Python โอเพนซอร์สสำหรับการเริ่มต้นการชำระเงินตามมาตรฐาน ISO 20022 แปลงข้อมูลที่คุณมีอยู่แล้ว — CSV, Excel, SQLite, JSON, Parquet หรือข้อความ SWIFT MT101 แบบเดิม — เป็น XML `pain.001` (โอนเงิน) และ `pain.008` (หักบัญชีอัตโนมัติ) ที่ตรวจสอบด้วยสคีมา XSD อย่างเป็นทางการ

ทุกไฟล์ผ่านการตรวจสอบสามชั้นก่อนถูกเขียน: สคีมา JSON ต่อระเบียน (รวมการตรวจ mod-97 ของ IBAN และโครงสร้าง BIC) กฎ scheme (SEPA และ CBPR+ ข้ามพรมแดน) และการตรวจสอบ XSD ขั้นสุดท้าย ยอดรวมควบคุมถูกคำนวณใหม่เสมอ ไม่เคยคัดลอก ทุกอย่างทำงานในเครื่องของคุณ: ไม่มีข้อมูลการชำระเงินใดออกจากโครงสร้างพื้นฐานของคุณ

## ลองใช้ในเบราว์เซอร์

ตรวจสอบชุดตัวอย่างได้โดยตรงในเบราว์เซอร์ — ไม่มีการอัปโหลดใด ๆ — และพิสูจน์ผลลัพธ์กับสคีมา XSD อย่างเป็นทางการ: [ลองใช้ Pain001](/try/) ไฟล์ CSV ตัวอย่างดาวน์โหลดได้เพื่อใช้เป็นเทมเพลตสำหรับการส่งออกของคุณ

## กำหนดเส้นตาย 14 พฤศจิกายน 2026

หลังการอยู่ร่วมกันของ MT–MX สิ้นสุดเมื่อ 22 พฤศจิกายน 2025 กำหนดถัดไปคือ **14 พฤศจิกายน 2026**: ที่อยู่ไปรษณีย์ที่ไม่มีโครงสร้างทั้งหมดจะถูกปฏิเสธในการชำระเงิน CBPR+ และรีเลย์ MT101 ระหว่างธนาคารจะถูกแทนที่ด้วย `pain.001` เวอร์ชัน 9 Pain001 สร้างที่อยู่แบบมีโครงสร้างและแบบไฮบริดได้แล้ววันนี้ — และแปลง MT101 ด้วยคำสั่งเดียว

## เริ่มต้นใช้งาน

```bash
pip install pain001
pain001 -t pain.001.001.09 -d payments.csv -o out/ --dry-run
```
